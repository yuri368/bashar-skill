关于“光明会”和负面事件

这是三个独立的问答，但是阐述了同一个问题，合在一起翻译了。

【光明会的力量幻影】

B ：你们瞧，这是一个非常有趣的，对力量自相矛盾的运用。你们星 球上有很多人对信息有非常强的控制。他们首先运用对信息的控制来让他 们看起来似乎能控制更多的东西。

当一些个体，再次重申，我不是说你们不应该知道一些个体也许持有 负面的意图，但是当许多人进入一个极端，便开始注视你们所谓的阴谋论， 他们就将这些力量，这些能够做出你们害怕的事情的能力赋予了那些人。 你们就这样给予了他们那种能力。

我这么说吧，这个大的玩笑就是，那些想给你最深刻印象的人，那些 想成为告密者的人，其实是他们的最大的鼓吹者，因为告密者们让人们相 信，认为那些人其实有能力做那些超出他们能力范围的事。那真是个天大 的笑话。

因此，你们自己要放下负担，不要给他们力量，并且你们将改变你们 的振动，进入一个他们最终不存在的平行实相里，是吧。那才是你们改变 世界的方式。你们不是改变你们所处于的世界，你们通过你们的行动，你 们的认知，你们的能量，你们的行为改变你们自己的能量。你们进入到已

经存在的一个平行实相，那里的能量能更好地代表你们自己的改变。这有 帮助吗？

Q ：是的。

B ：那么，一路顺风~

【负面企图】

Q ：你好，老朋友！我们上次交流时，我有一个问题，关于我们的政 府的...

B ：是的，我们谈起过共和制和民主制的区别，是的。

Q ：不是，不是那个，你说我们在逐渐成为我们自己的政府。 B ：是的。

Q ：我的问题是，我们的政府看起来，好几部分都和光明会银行家有 关系，有很清楚的，毫无疑问的是，有一些力量已经取得了控制权...

B ：打住！停止！ 丫的闭嘴！还有一件事是，那些支持恐怖的理论的 信息，绝不会从这个通灵管道里传递过来。【巴夏运用了最强烈的语气打 断了提问者的话语，所以这样翻译】

【听众欢呼】

Q ：这不是理论...

B ：停！我们想说的是，我们明白你所描述的那种人是存在的。我们 明白你们星球上有人的确持有那种意图。但是我们想指出的是，是你们所 有人将他们置于那个位置的！因此，如果你们不想要他们的控制，那么就

把他们移走。给你们自己力量，来给他们力量成为真正的人，而不是被恐

惧所驱使的人 。(Empower yourself to empower them to be true people and not people acting out of fear. )

并且，在一次请记住，不止有一个世界。你们在持续地在不同的平行 实相中移动，因此你们选择怎样的振动状态，你们最终就会体验哪一个平 行实相中的地球。如果你们一直把注意力放在那些试图掌控世界的人身 上，一直把注意力放在恐惧上面，那就是你们将体验到的。但是在同一时 刻，那些将注意力集中在给自己力量的人，将最终体验到另一个平行实相， 在那个实相里，那些人根本不存在。

Q ：那好，是否这个房间里的每一个人都在体验同一个实相呢？

B ：不是的。那就是关键所在。你没有搞懂这个。他们体验的不是同 一个实相。你们通过协议体验着类似的实相，但是他们实际上不是同一个。

Q ：那么，这个房间里有人对此一无所知并且不会被那些“联邦紧急 管理集中营”还有那 780 万件东西所影响了...

B ：正确！有那么一些人的确会被影响到，因为他们选择生活在恐惧 中。还有一些人根本看不到这些，因为他们没有生活在恐惧中。这是实实 在在的。

Q ：你能否告诉我...你能不能分享一下，是否这个星球的人口会被大 量减少？

B ：哪一个星球？

Q ：地球。

B ：哪一个地球？

Q ：当前这个实相...

B ：你没有懂！你以每秒十亿次的速度从一个平行实相切换到另一个 平行实相。请决定哪一个是你喜欢的实相。有一些地球人口会衰减；有一 些不会；任何你能想到的不同结果都是真实的。请切换到你喜欢的那个去。 他们都是真实的。切换到你偏爱的那一个。完！你懂了吗？他们都是真的，

切换到你偏爱的那个吧。

Q ：是也不是，我懂你所说的...

B ：很明显，你不懂。

Q ：你说的对，我不懂。我希望我知道怎么切换到一个...

B ：你现在就在切换！你一直在切换。切换到拥有你偏爱的能量的世 界的方法就是使自己先成为那种能量，不要再相信恐惧的信息。

Q ：但是我是去观察我周围的现实世界，然后加以解读。

B ：你忘了我们所说的，每一件事物从基本上来讲都是中性的，没有 内建的，预置的意义。它看起来是什么样子的无关紧要。记住，你们改变 对于事物的判断，并不是基于外部有否改变，而是基于你们是否与外界的 改变共鸣，却不是事物的外表如何。那样，你就能知道你不会被任何你不 喜欢的东西所影响。因为那是你自己创造的能量状态，无论外界事物看起 来像什么，无论任何人对你有任何企图，你不可能被别人的企图影响到， 除非你相信你能够被影响，或者你选择被影响。

Q ：那么，现在在这个实相里，有人可以回头去看着过去，但是不会 因为过去任何行动而造成负面的结果？

B ：正确，好好想想吧。

Q ：谢谢！

【化学凝结尾】

Q ：还有个问题？

B ：好的。

Q ：你们在飞船上肯定注意到了那些在全球喷洒的化学凝结烟雾。

B ：时不时地~

Q ：我的问题是，我想知道那是为什么？我不知道是否他们自己觉得 自己是在带着好的意图去做这事，或者他们真的只是想干掉我们？

B ：他们在某种程度上，收到了一种误导，他们认为需要以某种方式 来做某些事来平衡你们星球的气候变化。但是问题是他们实际上在空气中 注入了许多的毒素，因为他们没有用到需要用的物质，黄金。

Q ：单原子金？

B ：是的。如果他们使用了它的话，他们就能够将你们星球的气候平 衡住，而不会有任何毒副作用。但是因为你们都黄金的价值观是完全不同 的，你们只是将黄金囤积起来，而不是在这类环境下使用它，来促进全球 气候模式的改善。

现在，你们所经历的在某种意义上来讲是一种自然周期，虽然它被你 们星球上的人所使用的科技的东西大大地加剧了，但是你们星球的暖化和 冷却的周期是自然的循环。问题是你们本可以使用恰当的科技让这种变化 得到舒缓地平衡，但是你们没有这么做。因此，从这方面讲，他们有那么 一点在想，他们是在“试图”平衡这些事情，但是就像你们所认为的许多 “改善”生活的东西一样，它们大多数是非常有毒的。是吗？

Q ：是的。

B ：好啦，还有其他事情与这化学凝结烟雾有联系，但是我们不想再 深入讨论。我们将停留在表达事实和科技的直接联系上。现在我们不想讨 论其他可能有关的特定意图。

你们想待在负面的世界吗？

Q ：不想。

B ：那么我们就不要再增强负面性了。
