# 巴夏 126 采取行动



翻译： 尚林

B ：…这两者是一回事，并不相互排斥。以你们的语言委婉地说就是，

你们通过作为“榜样”，通过成为你偏好的那个世界的能量振动，来帮助 改变你们的世界，并转换自己进入那个已经代表了你偏好的振动的平行实 相。因为，在那个转换过程中，你就成为别人的榜样，使他们也能够选择 那种类型的转换。

这就是你“帮助”改变世界的方式。虽然，实际上你并没有真正改变 那个实相的任何事物，只是转换到另一个实相，之前那个实相依旧存在没 有改变， 因为所有的平行实相都同时存在着。所以，看似矛盾之处在于， 你帮助改变你所在的世界，实际上是通过，以最佳可能的方式转换进入另 一个实相，那个实相更加代表了你所偏好的世界。因为，在此过程中你起 到榜样和示范作用，令别人也能这样做。你搞清楚了吗？

Q：是…是的。

B：你确定吗？

Q ：呃，是，我我我明白了。

B ：你你你听起来有些迟疑。

Q：哦，不。因为我的某一部分，有时会感觉会情不自禁去亲自动手 参与那些事情。

B ：哦，那就以任何方式去做。“亲自动手”和“参与”就是我们所说 的“行动”啊。你必须采取物质行动，因为你是在体验一个物质实相，那 就是我们说的“作为榜样”的意思。如果你真的相信某一特定的振动实相， 那么你就会作为榜样在实际行动中真正体现它们。你必须将那种振动导入 物质实相，否则那就只是一种心智练习 (mental exercise)，你就没有完成 一个回路 (completing the circuit) 。你必须“身体-心智-灵魂”(body mind spirit) 谐同运作，而不只是在“心智”层面。懂了吗？

Q ：是的。

B ：因此，通过采取行动，将你意愿的能量物质化、结晶化，以最具 可能的方式，真正辐射出你偏好的实相的振动。因为如果你身处那个现实 内，你的行为自然会与之匹配，你就会以任何使你喜悦的方式采取物质行 动，就像你说的感到“情不自禁去行动”。懂了吗？

Q ：是的。

B：当你诚实地与你的真我对齐，并且没有期望时，那么你就成为了 一个“榜样”。以这种行动，你就是在真正将那种振动锚定在那个实相中， 成为别人的榜样。那些人就可以选择是否去模仿、反映、同步对齐于你所 给出的示范。说得通吗？

Q ：可以。

B：理解了吗？解答你的问题了吗？

Q：是的

B ：谢谢。

Q ：谢谢。
