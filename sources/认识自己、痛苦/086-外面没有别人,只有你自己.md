# 巴夏 115 外面没有别人,只有你自己



翻译： 尚林

Q：你好， 巴夏!

B：你好！

Q ：我想在前面那个问题的基础上，继续探讨你刚刚讲的主题 B ：好的

Q：我怎样才能通过改变自己，来改变我对周围人们——特别是那些 使我产生“负面体验”的人们—— 的看法？

B ：好的。首先，你得通过不再给你现实中的任何事物贴上“负面” 的标签，来开始改变自己。因为如果你为它们贴上“负面”的标签，那么 你所做的就是认同于它们，并使自己一直坚持那种观点。不是吗？

Q ：是的。

B：其次，如果你感知到某人所做的某事，它发生在你的现实中，或 者是直接影响到你时，要明白我们刚才讲过的：你正在创造出你那个版本 的他们。你必然在你自己意识之内的某个地方认同于那个观点，以使你能 以那种方式来感知到它。

现在我们知道，你们能够中性地、客观地观察到，某人可能正处于负 面状态，即使你现在没有这样去观察。但关键在于，如果你知道它与你无 关，那么你就不会把它放在心上。你会感受到被它影响的唯一原因就是， 你认同于它了。明白了吗？

Q：好的，我以前想要 …

B ：等一下，我还没说完。

Q ：好的。

B ：如果可以的话，我想举例说明一下。

Q ：绝对可以。

B：谢谢，你最喜欢什么颜色？

Q：蓝色

B：好的。现在，如果你穿着一件蓝色的衣服，有个人向你走过来说 “我讨厌红色，所以我讨厌你穿的这件衣服。”你会想：“什么？不懂他在 说什么。噢，他的话肯定和我没关系，他肯定是疯了，他肯定说的是其他 人吧”你不会被他的话影响到，因为他的话对你没有意义。

你明白吗？你将不会对它产生真实的情绪反应。所以，当你对某人的 恶意攻击感受到了情绪反应，你所做的其实是，使他们——你那个版本的 他们——反映给你，你的某个部分以那种感觉方式去感觉你自己。否则， 你就不会起反应。你只会观察：“哦，有趣”，然后继续自己的事，不受其 影响。但是如果你对它起了反应，那就是在展示给你：“嗨，你的某个部

分竟然买入/接受了它，把它当成真的了。”

那么，你要怎么办呢？你可以说“哦，谢谢！谢谢你向我展示出，我 没有去爱我所有的自己。”当你真正开始这样做的时候，接下来你可能会 开始看到，其他人对你的态度可能也随之改变。因为你所做到的就是，你 已经改变了在你实相中的“你那个版本的他们”，使他们更加反映出一个 事实，即你现在能更完整地爱你自己了。

那些人也许仍然会到处攻击或污辱其他人，但是，你经验到的就只是 你已经创造出的“你那个版本的他们”，它现在反映出的就是爱，是你以 前不愿意、而现在愿意给予自己的那份爱。你开始有点明白了吗？你能看 出这是怎样一种“影子戏”了吗？

Q：是的，这很微妙。尤其是当你与那些人在同一个房间时却又不能 … . B：尤其是当你“想象”你与某人在同一个房间时。

B：记住，它不是真实的，它不是真实的。它只是你自己的现实体验， 并非验证性绝对真实的。它只是一个“象征”，是你正在自我创造产生的 那个实相的象征，是你自我经验的象征。所以，仅仅是看起来好像是“其 他人与你在同一个房间”。其实他们不在那里！他们在他们自己的“房间”， 也许正在与“他们自我版本的那个你”在一起。

所以问题在于，你喜欢在“你的房间”创造出什么？因为“你的房间” 里只有你自己一个人。不论看上去是怎样的，但“你的房间”里就只有你  自己。你是否熟悉你们星球上有一部科幻电影名叫《星际迷航》？

Q ：是的。

B：你熟悉里面那个“全息甲板”吗？

Q ：是的。

B：你是否理解其他所有的人都只是全息影像？

Q ：我在智力上理解那。

B：我就喜欢你刚才那句话。无意冒犯，无意评判，不过你这句话最 终听起来像是逃避。

Q ：是的。

B ：我知道，你刚才说的“智力上”，其实是另一种方式在表达：我不 确定是否想进一步搞清楚你在讲什么，这是在推开问题。因为你确实非常 清楚我在说什么，你的内心深处知道，你的灵魂深处知道。只是你被灌输 的观念让你害怕更加靠近地看清楚它。

Q：害怕看清楚“全息图的真实体验”这个概念吗？

B ：是的。因为这就是你们的处理方式。当你们面对这类情况时，你 们大多数人都这样处理。

B：你们害怕真正看清楚它来处理它。因为，你们被灌输去害怕的是， 你认为别人关于你的评论有可能是真的。“噢不，那会有多么可怕呀！”你 能听懂吗？如果你足够深入的去查看就会明白，你是在害怕别人的评论可 能是真的，要是这样你该怎么办呢？但我要告诉你，那从来都不是真的！ 只有你决定某事物对你是真的，它才是真的。理解了吗？“智力上”的理 解？

Q ：谢谢你的提醒。

B：好的。那么现在你要说什么？

Q：我在准备来参加这次聚会之前， 曾以心灵感应的方式与你进行过 一次沟通。在沟通里，我请求你帮我找到那些障碍我更好的生活的个人阻 塞。

B：我现在是在做什么？

Q ：不。昨晚你进到我的梦里了，我想知道我们干了些什么。

B ：这种沟通，更多的这类沟通。

Q：我们在做更多的这类沟通？

B ：是的。

Q：好的。那么你能否具体地为我阐明我的灵魂协议和人生目的？

B：显然，你已经决定要学习的灵魂课程之一就是：在别人的反对声 中找到自我价值。你是要相信你自己的真相呢，还是要相信别人的真相— —那些其实与你毫无关系，你更愿意相信哪一个？

Q ：我相信我自己的真相。

B ：好的。那么你可以继续选择这样做。任何时候，当你发现你害怕  别人对你的评论，或者你因别人对你的议论产生情绪反应时，要理解，那  只是另一个机会让你感觉到你的自我价值并相信你自己，而且要明白：很  多时候，当某人走到你面前说一些看似攻击你的话时，他们真正所做的就  是在告诉你：“他们和你有同样的恐惧，他们只是把那恐惧投射给了你。” 他们以这种方式为你提供一个机会，让你决定它对于你是否是真实的。

这时你可以做的是，让自己足够广阔以容纳一个空间，容许他们去发

现，他们是否真的还需要继续接受他们的恐惧为真实的，通过向他们送出 爱，为自己展示出一个机会来更加爱自己。懂了吗？

Q ：是的，谢谢。

B：有帮助吗？

Q ：绝对有，谢谢你。

B ：好的，我们还会继续讨论。

Q ：谢谢，梦里见。

B ：对，我就是那个意思。
