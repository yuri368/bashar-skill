# 巴夏 13 放下希求心



(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/TyW-BEy1Ah0.html)

翻译：湛羽    整理：风总是吹

再次提醒各位，所有人，请谨记。我不是说事情 (你们的心愿) 无法 彰显，也不是说它们不会发生,但有一点非常非常关键的地方请各位记住： 关于这点我们在传递巴夏讯息之初就讨论过，“物质心智”(physical mind) 和“高我心智”(higher mind) 的能力是不同的。

我们知道，你们很多人在生活中都有想要实现的梦想、愿景,你观想 着那种理想生活的完美画面,你为之向往，你为之努力,它激奋着你,令你满 怀热忱。这些都没问题。但是一定要清楚地理解一点：“小我”能想象出 (实现心愿) 的最好的可能性，恰恰只是“高我”想象中最局限的可能性!

所以,不要让“小我”的声音阻止“高我”，说“那就是我能得到的最  好的”。让“高我”向你展示更多你能得到的， 比你之前相信的还多。因  为如果你坚持“小我”能设想的就是最好的版本,你实际上限制了“高我” 以更赞的方式把一切带来给你。你那小小的心智会说：“噢，就是它了，  那就是最好的”。于是你为“高我”的无限智能设置了条件、限制和期待，

阻挡了它本能带给你超乎你想象的精彩的到来。

所以你“小我”心智能想的最好的，是最局限的可能性。带着这个理 解去生活，看看一切会变得如何。你自认为最好的方式，实际上最局限， 最不容易发生。它不是最好，而是最局限。放下小我的版本，然后感受你 真实的力量。在臣服和接受之中允许更好的一切自然发生，朝你而来，只 要你受得了那么多好事。

请再次谨记：你不需要去“迫使”事情发生，事物已经在自行运作了。 “小我”的心智是不是理解这个发生过程并不重要，因为“小我”一旦开 始思考，就开始干预。比如当我思考“这事该怎么办才好”，我不是在允 许它发生，我是在催促它发生,干预它按照一定思路去走，而不是信任事 物的自行运作。如果事情已经在运作了，你就让它们发生吧，你允许它们 发生就可以了。

你可以发出想要某事成就的信号，你可以用观想什么的来把自己带入 相应的状态和振动频率。不过，然后请放手，让“高我”来接管。就这样， 这就是你需要做的。

当小我喊着：“我充满灵感，我做完了观想，我感到喜悦和兴奋，我 同高我连接上了。”你需要做的就是，看看周围的环境和状况中，有什么 事情是包含了同样的喜悦，兴奋，激情,然后以这种喜悦感为指南，尽你 所能地去行动。一个情景来了，这样去做，再下一个，依次去做。清楚你 正被引导着，通向你真正的自我。

就这样走下去，享受你的旅程。相信无论发生什么，都是需要发生的， 确定无误。用你喜欢的方式，积极地诠释每一件事，哪怕你一时不能理解 它的含义。试着积极地理解它，允许它向你展示精彩。

请记得：你无法经验你的振动频率达不到的。所以，如果你不处于开 放的频率，如果你不处在一个积极意义的频率，事物如何积极地向你彰显 呢？如果你一直紧抓着那些你不想要的信念和定义，你就会一直以你不想

要的方式来反应。这是个很简单的问题。当你以消极的方式去反应，消极 地理解一些事物时,你需要做的只是后退一步，对自己说：“我究竟相信了 什么，会让自己如此消极反应？我更愿意相信什么，能让自己积极地反应 呢？”

很多时候，一旦你识别出你真正愿意相信的东西，消极的事物就消失 了。它消失了，不需要更多的手段。很多时候，仅仅点亮一盏灯，阴影就 消失了。

但你得允许自己审察小我的思想，最简单的方式就是自问：我为什么 非得相信那些让我活得如此消极的信仰?找出那些信仰是什么，找出它们 来自哪里，看看它们是否仍然适合你。如果不适合，实在没道理再背着它 们。它们大多数时候只是包袱，而你总是背着不属于你的包袱。

丢掉它那些旧信仰!它是如此沉重的唯一原因就是因为它其实并不属 于你!放掉它,你将感到轻松。再次谨记，如果你想身处光中，那么就自己 点亮自己。(Remember again you want to be enlightened,just lighten up on yourselves!)

不要再这么苛刻而不恰当地对待自己了，拖着不属于你的沉重包袱蹒 跚前行。可能这些(旧信仰)来自你的父母，来自你身处的社会，或是你的 朋友，都不要紧,都可以丢掉。
