# 巴夏 96 与小我谈判协商(1)



翻译：古手羽入

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/KaBNXQ0Jsrc.html)

Q：我在想“小我”对“跟随你的兴奋”可以有什么助益或阻碍？ 比 如有人想尝试新生活，这可能会牵涉到辞职，但他们对那样做在经济上的

后果有很多焦虑。那么人们要如何才能够调和高层意识与物质心智之间的 能量， 以使他们恰当的各行其职呢？

B ：首先，你必须以你觉得必要的程度，尊重你现有的旧信念体系。 换句话说，你先对“小我”所创造出来的信念体系给予肯定尊重，然后认 识到从“小我”或物质心智的视角看它们(旧信念)是有根据的，正当的。

因此，你不是要摒弃它，而是与之合作。可以说你来做一笔交易，你 对“小我”，“物质心智”说“你猜怎么着，我会继续与 90%的那个信念体 系合作，但是给我仅仅 10%的余地来玩别的，那么我会让你看到那 10% 其实真的是可行的”

与“小我”谈笔买卖，让他给你一些跨出去的自由。即便是只跨越一  丁点你觉得是你自我维持所必须的信念体系。随着你不断的做这些交易，  你会一步一步的训练“小我”去明白，随着你要求越多的自由度，“小我” 其实会觉得自己越来越被支持。然后他也会愈发给你更多的自由度，直到  有一天你环顾左右，发现所有旧的信念体系都消失了。并且你允许自己被  新的， 以适合你的方式的信念体系所支持。

第二件事是，当你在进行上述那种交易的过程中，同时致力于“重新 定义你使用的观念”。

比如，“你的人生能够被支持的唯一方式，唯一能够让你去做自己渴 望去做的事，必须依赖某种特定的形式，或者财富象征”这样的观念。

记住我们对丰足的定义“在你需要做某事时，去做的能力。句号！”

如果金钱在你们星球上属于这类东西，那也都没什么不好。但重点在 于，实质上你只是需要“在你需要做某事时，去做的能力”。那么如果金 钱，不见得绝对是做那件事的最佳途径，那么你的实相，你的高层意识其 实是会给你带来让你以更轻松而达到目的的事物的。

因为有时候如果你坚持金钱是唯一某件事能被达成的方式，那可能相

当于自设出来一个障碍去撞头。其实你的高层意识是能够以一种让你更轻 松方式来达到目的的。只要你软化那种认为自己需要什么的定义。

所以通过致力于改变“为了达成偏好，而自以为某事物是必须的”那 种定义。同时，与“小我”做交易，来让它给你些余地去跨出旧信念一点， 但同时又不去硬碰那些你真的觉得还无法改变的信念。如此，你就可以给 自己做出一个合理的节奏，来平衡的，全面的让自己意识的各个部分，参 与其中。那么逐渐的，你会发现自己能够改变。

Q：如果“小我”在这个过程中被吓到了，它会不会水你？

B：当然可能。但这正是你要谈交易的原因啊。你需要找到一种行得 通的协商方式。因为“负面小我”唯一会水你的情况是，它觉得它没有真 的得到一个公平的交易。如果它觉得你在回避它，试图绕开它，和他兜圈 子，懂了吗？

Q ：听起来像做生意一样。

B：本来就是做生意。因为“小我”本来就只与物质交易，物质世界 相关。因此，一个不错的方法是运用它的语言与之交流，和它协商交易并 允许它明白你希望公平的协商。所以如果你的协商从“小我”的观点看是 公平的，以此让你在协商中获得一些余地，那么就它就不会觉得有理由想 要水你。要是被水的话肯定是因为你协商的不公平。

Q：这听起来很震撼，因为这真的是关于理解“小我”的语言，并以 他乐于接纳，接收的方式与之交流。

B ：肯定的。全都是在于对定义的理解和进行处理。

Q：那个，我想确认一下，是哪部分意识在与“小我”谈交易？

B： 问的很好！因为你看，这就是意识的聪颖灵动之处。其实与“小 我”谈判的那个正是高层意识(高我)。通过提出要公平协商这回事，你 就已经把高层意识带入席来了。并且高层意识就开始与物质心智公平的协

商谈判了。因为高我只与平衡与公平相关。但你在运用物质心智的语言来  让这种交流得以成立。所以这个协商中，高我小我二者都在。就是这样，  二者都在席。甚至光是提出协商这种想法，你就已经把“小我”和“高我” 都拉到台面上，来为这个“人”的全然，做出最好的协定整合。这就是这  种协商谈判的基本内涵。你在给牵涉进来的所有部分都做出公平的协定 ！  兼顾整个自我的全然，兼顾其两面，两极。好吗？

Q：真棒！我明晰化了很多，关于如何进行自我不同面向之间的对话， 进而成为一个和谐统一的人。
