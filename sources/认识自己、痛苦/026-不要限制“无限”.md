# 巴夏 23 不要限制“无限”



翻译：Deepcall    整理：风总是吹

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/SfCDD55g9u8.html)

Q ：你好， 巴夏。

B ：你也好！

Q ：我的问题是，“存在”来自哪里？

B ：它自身。它并不来自任何地方。你的问题本身并不能对应你所问 的概念。“存在”不来自何处。它只是存在着。

Q ：怎么会?那不是虚无吗?

B ：是的。但就算是“无”也是一种存在。“无”并不等同于我们观点 中的“不存在”。当你说“无”的时候，你实际上指的是“不存在”，是吗？

Q ：不，我的意思是似乎在很久以前……

B ：在“存在”之外，是没有“很久以前”的。你或许会很迷惑。因 为，是这样的：时间存在于“存在”之中。而“存在”并不受时间支配。 时间是一个在“存在”之内的概念。而“存在”并不是时间之中的概念。

Q ：但一切总该有个开端……

B ：我明白对于你来说看似如此。在“存在”之内，有着起点与

终点，但它们却不是针对“存在”自身的。

Q ：那它是如何被创造出来的？

B ：它没有被创造出来.它就是存在着。创造只发生在“存在”之内。 你所能想象得到的关于根源、创造、起点等等的一切概念，都是“存在” 范围之内的概念。没有“存在之外”

Q ：凭人类心智是不是无法想象或描述“存在”？

B ：是的。因为你无法想象“不存在”。注意“不存在”的定义，根据 定义，没有关于“不

存在”的描述或体验，“不存在”意味着没有任何的体验，所以 你无法体验到它。因此，理所当然地，你就无法表达“没有体验”。 你能够描述的体验，只能来自于“存在”。“存在”的另一面， 以及 “存在”之外，之前，都一无所有。它仅仅存在着，不属于任何事 物“之外”、“另一面”以及“之前”。那些都是“存在”之内的概念。

Q ：那么，“存在”是否也在扩展着，连同它自身一起？

B ：某种意义而言，于“存在”之内是这样的。但不是它本身。

Q ：我理解不了。

B ：我知道。“存在”存在着。它即它所是。但在自身之内，它能够拥 有成长，扩展，学习，以及变得更加更加更加的无限。然而，尽管它在自 身之内不断经历着一切，它自身永不改变。因为它只是简单地存在着。

Q ：哇哦。

B ：明白了吗？

Q ：并不完全……

B ：我知道，我知道(笑)。
