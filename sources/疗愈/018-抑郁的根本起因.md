# 巴夏 76 抑郁的根本起因



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/RUCpJwbF5gg.html)

Q ：很高兴再次和你对话， 巴夏。

B ：我也是。

Q：好的，请问你能不能谈谈有关抑郁的问题， 以及怎样帮助一个人 走出抑郁。

B ：好的。直接克服它。

Q ：哦，不，我刚才说的不是我。

B ：我知道，我只是要说：直接克服它。我不是故意要说的似是而非， 我来解释一下。首先，你必须知道，在你们的星球上、社会里、种群中， 很多你们所谓的情绪状态，及其可能引发的精神状况，它们首先、首先、 最先都是源于“对自我价值的贬损”。能听懂吗？

Q ：是的。

B ：因此，恢复治愈这类问题的主要因素是“对个体价值的肯定”。 必须让他们感受到自己的价值，重要性，(值得拥有的) 认同感。必须让 他们知道，他们是被爱着的，被支持着的，值得被照顾的。这可以通过多 种具创造性的方式来教导、反映、展现给他们，当然个体差异决定了什么 方法、映像、事例最合适他们。

但这一切都必须挂钩于你们说的“重要性，认同感，根本价值肯定” 之上。必须以此为基础。然后才会有所进展。一旦一个人意识到：存在即  是价值，因造化从不做无价值的事。所以如果他们明白：自己的存在，本  身就是一种认可。他们将找到自我价值，然后在那基础上添砖加瓦，以他  们自己的方式进一步表达自己的价值所在。你听明白了吗？
