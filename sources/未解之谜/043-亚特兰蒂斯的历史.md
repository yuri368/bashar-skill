# 巴夏 108 亚特兰蒂斯的历史



翻译：文森

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/SsuQOhMwEgA.html)

Q ：我对亚特兰蒂斯非常着迷。我确信我们当中很多人包括我自己都 来自亚特兰蒂斯。万圣节是…

B ：那是亚特兰蒂斯毁灭前一天的纪念日。

Q ：那时到底发生了什么？ 比如说，那时的我们都做了什么，那次毁 灭中哪些人牵扯其中？谁在帮我们谁又在袖手旁观？ 因为我们知道我们 当时在和其他种族联系，而且他们帮助过我们。

B ：是的，但是你同时也是在问一个跨越了成千上万年历史时期的问 题。

Q ：只是一万两千年前那会儿，当我们确确实实的……你知道就是一 万两千年前嘛，你知道我在说什么(亚特兰蒂斯毁灭的时期)，想弄清楚 那时我们做了什么 …

B ：有些事情你们做了，有些没做。那时，亚特兰蒂斯文明的振动能 量被瓦解破坏了，这是由于众多派系和极性的存在所引起的，从这个意义 上，你可以说正是因为在能量振动被破坏的情况下，那些存有们自己吸引 招致了文明毁灭的现实实相。

Q ：地球变动？

B ：是你们所说的“陨星撞击”。在你们所说的大西洋海底，你会找到 行星撞击留下的伤痕，尽管之前很多自然和地质的灾害同样也发生了，但

是最终是撞击引起的巨大海啸将亚特兰蒂斯文明抹去，基本上只留下你们 现在所说的加勒比群岛作为文明遗迹。能理解吗？

亚特兰蒂斯无疑是一个高度发达的文明，在众多领域拥有高水平的智

慧，但不是你们所谓的最高文明层次，他们经常和其他文明的生命形式保 持频繁交流和直接的互动，但是，他们的确拥有大量知识。在你们星球上 其他文化里所存留下来的，大多可以追溯到亚特兰蒂斯的知识。

某些建筑和疗愈的方法，某些仪式，某些所谓的神话传说，都代表了 当时亚特兰蒂斯时代的那些事情。现在，你们在某种程度上说在一个完整 循环中回来了，很多很多原来的亚特兰蒂斯人在转世回来，特别是转世到 欧洲和美洲，从而给他们自己一个再来一次的机会，来决定是否想重蹈覆 辙，抑或这一次改变自己的内在，从毁灭循环中重生。所以是你们给自己 留下的标记和信息，来提醒自己过去发生了什么，从而决定要不要再发生 同样的事情(毁灭)。

Q ：现在离万圣节只有两天了。是否有能量从那儿(亚特兰蒂斯) 通 过细胞记忆或者别的方式传过来影响着我们吗？

B ：除非是你们选择愿意与之创建这样的连接，否则这不会对你们有 影响。如果你们希望通过万圣节来表达你们对亚特兰蒂斯文明所经历的道 路的致敬，那么就只管带给它崇敬，带给它承诺，带给它改变。崇敬它， 让那些经历体现出价值，从中学到教训，然后不要重蹈覆辙了。
