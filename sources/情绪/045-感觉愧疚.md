# 巴夏 54 感觉愧疚



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/-h--9_GsB-Y.html)

Q ：你好， 巴夏。

B：等一下，等一下。我们正接收到更多的具体信息：对你来说，我 们的是 C 与 D 泛音。他们则是 C 与F 泛音。有帮助嘛？谢谢你。

Q ：嗨， 巴夏。

B ：你也日安。

Q：很欣慰能再次与你互动，我想说你是如此的令人快乐，如此的可 爱，我们非常感谢你对我们的帮助。

B ：我们谢谢你分享你自己的愉悦与爱。

Q ：真好！嗯，谈及昨天说的，1986 年夏天我在卡拉巴萨斯和一群人 组团参加天空观察集会。岱罗也在那，不过他好像不记得了，我的确记得 看到了他的。我们真的观察到了 UFO 母舰，好大啊，而且超兴奋，它们 有红色的四处跑的光，并且最妙的是他们还向我们闪烁了两次他们的光来 打招呼。从那以后，我不记得他告诉了我什么，但他看到了的，但我从来 没问他们是谁，我试着推出他们是谁并且有了三个想法，但我不确定，我 想关于这个也许你可以帮助我，以及那种觉得他们是家人和朋友，或和我 很有关联的感受。

B：是的。那是一个不同种生命的组合，有些是灰人 (grays)，有些 是混血种族 (hybrid)， 有些是昴宿星人(pleiadeans)， 有些是天狼星人 (sirius)。

Q：有一个叫阿斯塔 (Ashtar) 指挥的团体，我最早完全觉得我是其 中一员但我一直没感觉到……

B ：不是。

Q ：谢谢，因为我觉得那是另外的东西。

B：阿斯塔指挥部这个观念是地球人对一种高层意识的转译，这种高 层意识在你们的实相内被显化转译为一个地外文明，但其实不是。

Q：好的。他们很友好，我很高兴能看见他们，并且想再看一次。有 本关于混血种族的书叫《瑞秋的眼睛》Rachel’s eyes ，这书说的是真的吗， 我们当中还有星际混血儿？

B：本质上书中有些概念是准确地代表了描述对象，但其中一些从某 种程度上讲也是一种类比或比喻。

Q：好的。最后一个是关于责任与愧疚的问题。我今天意识到我会对 我不得不履行的责任产生激情。

B：这应该是“对”某个对象负责，而不是“为”某个对象负责。 Q：对我自己负责？

B ：以及对别人负责。做你自己就是对别人负责。但你不能够为了别 人负责。

( Being  yourself is  being  responsible  to  others.But  you  cannot  be responsible for others. )

Q ：对对对。我明白。好了，这是我的两难之境。我觉得我都分裂了， 每个人都指出我这个。东海岸，西海岸，上有年迈的父母，下有待照顾的 孩子。我甚至感到了愧疚，因为我对责任感到生气，直到产生沮丧和愤怒， 因为每个人都是我的一部分，我没拥有自己的一部分，然后我试着……反 正我就是觉得很分裂并且我……

B ：你什么时候才会花时间与自己相处？你什么时候才会平静回完整 的自己？

Q ：这是个好问题。我什么时候才会？好的，请帮助我平静自己吧。

B ：让我在你想这个的同时，指出某些事。如果你不允许你自己做你 自己，你也无法帮助任何人。

Q ：确实如此。

B ：当你是你真正的自己时，尽量地跟随你的激情，然后一切将会自 行安排到某个程度，来让你理解你究竟要对别人负责与互动到哪个程度。

超过这个程度，就不是你的责任了。如果超过了这个程度，即使别人说那

是你的责任，那也只是他们自己的问题，而不是你的问题。你明白吗？

Q ：是的，那就是我想赶走的那种我感觉到的罪恶感。

B：帮助你澄清了嘛？

Q：绝对是！

B ：谢谢你。

Q ：非常感谢。
