# 巴夏 155 艾莎莎尼接触水晶介绍



翻译：柯维

(视频：http://www.tudou.com/programs/view/hN7x9auA_cw/ ?resourceId=0_06_02_99)

岱罗：

巴夏曾经在几次对话中解释过他在他的星球上的生活和经历，他描述 的中央那块水晶是块深绿色的六边形水晶，比这块要大很多，但是这块水 晶基本上就是巴夏向我们描述过的那块的复制品。

巴夏：

在我的世界，当我还是个孩子的时候，他们为我展示了陈列在大型艺 术展览中的，由另一位接触专家制作的、中央是六边形的水晶。中央的那 块水晶，按照你们的尺寸来说，大约是 3 英尺(0.9144 米)。那些水晶都 是同样的绿色，中央的那块水晶周围还有其他的水晶，每一块叠加到中央 水晶的水晶都代表了与我们的文明进行了第一次接触的另一个文明；代表 了所有其他与我们接触过的文明。并且有越来越多的文明不断地加入到了 星际联盟的世界，但是中央的那块水晶是承载了接触本身的振动的种子水 晶，它代表了我的家族与其他的若干个家族一道成为了接触专家群体。

岱罗：

有一个符号印刻在这块水晶上，是一个三角形的符号，中间有一个螺

旋，巴夏描述的这个符号实际上是他的家族徽章。它代表了巴夏的家族作 为不同文明接触专家的传承。巴夏建议如果我们制作了那块水晶的复制 品，即使复制品比中央水晶稍小一些，实际上做的是按照 DVD 上巴夏教 授的方式对每块水晶进行一种特别的冥想，目的是为了将水晶充入特别的 接触频率，那么当你使用这种水晶进行冥想时，实际上就是用代表了巴夏 的文明的特别频率进行了充能，这种特别的频率代表了他们与我们的最初 接触。

我们的大部分复制品都是石英晶体制成的，剩下的一少部分是有玻璃 制成的，相对会便宜一些。这两者间的区别是：当你进行冥想时，石英晶 体版的一次就可以充能完好，玻璃版的需要时不时的进行冥想充能来恢复 频率，因为玻璃会很快丢失充好的能量。

所以，基本上巴夏说的是用你自己的能量为这些水晶充能，在冥想中

这种能量就像是某种你为接触进行了特别的投票，如果你对这种水晶感兴 趣的话，请到后边桌子的工作人员那里询问，他们会提供相关的信息，还 有这个可爱的盒子以及相关的 DVD。请到后边桌子那里获得相关的信息。
