# 巴夏 111 怎样有更多机会与 UFO 接触



翻译： 尚林

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/4mXBX3yFW7o.html)

Q ：我还有一个问题。

B ：好的。

Q ：我曾有过一次 UFO 接触 (contact) 经历，当时有外星生命来试图 与我接触，但我当时害怕了。

B：他们不是“试图”接触你。

Q ：噢，对，不是“试图”。他们当时到来并与我接触，但是我当时很 害怕，于是把他们推开了，我不是故意要那样的。

B：好的。你知道，那是一个标尺。通过被接触者的反应，我们确定 他是否准备好了进一步的接触。

Q：是的。你能否给我一个特殊许可，让我能再次有这种接触的机会？ 我愿意有进一步的接触，但是我还不曾有过...

B：我将给你以下建议：你对你自己能量感觉到的舒适度，正体现了 你与 UFO 接触的适合度。所以，无论你们在接触的哪一阶段，我们能给 你或你们任何一位，关于接触的最强大的许可，就是告诉你，关于接触的 所有的约定，所有的议程都已经被设定好了。你们无须请求任何特别的东 西，你们也无须去做任何特别之事，你们只须实践你的最高兴奋，全然活 出真实的自己。

因为，活出真实的自己，就是允许你成为接触约定被订立之时的那个

你。一旦你允许自己成为那个你，就绝对没有任何事能阻止接触的发生， 如果曾经有过这个接触约定的话。只有一个例外：如果你把时间用在担心 接触约定无法实现，那约定就不会实现。

这是个悖论。但是，有关接触的一切都已经设定好了，所以，你只要 用心生活，并活出真实的自己，那么绝对不会有任何情况会令你错过这个 已经设定好的安排。懂了吗？

Q ：是的。

B ：你要允许自己去理解，生活已经在自行运作了，你所要做的就只 是"允许"它自动发生，你不需要去"做"什么去让它发生。理解这之间的 不同了吗？对你有帮助吗？

Q ：是的，是的。

B ：谢谢。

Q ：谢谢。

B：补充一点，你们现在就正在进行“接触”。

Q：当然啦！

B：因为我们正在通过一个生物转译器讲话或发送思想，那并不意味 着你们没有在“接触”

Q ：谢谢。
