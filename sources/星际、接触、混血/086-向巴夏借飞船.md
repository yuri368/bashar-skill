# 巴夏 104 向巴夏借飞船



翻译：柯维

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/qqI6C2vkcQk.html)

Q：我有两个问题问你。我可以跟你借一艘飞船吗？出于善意的目的。 B：为了什么目的？

Q：善意的目的。

B：好的,可以, 自己来取。(观众：哈哈哈)

Q：实际上，我的第二个问题，你一定懂我的意思，你是飞船驾驶员 吗？

B：是啊。

Q：我非常乐意去取飞船。谢谢。

B：好吧，请大家都记得。你们都有这个所谓“出体”的能力去做那 样的事情，而且你们中大部分人都有过几次类似经历。现在的观念就在于 开始发现到物理的现实与梦境没有什么不同 ( start to see physical reality as no different than the dream)。因为，确实没什么不同。 你们只是这么说而已。一般而言，你们大部分人将物理现实定义为与梦境 不同，但不是那样的。那不过是另一种梦境罢了。所以，可以。你获得了 我们的许可来拿飞船。随时来取飞船吧。谢谢。
