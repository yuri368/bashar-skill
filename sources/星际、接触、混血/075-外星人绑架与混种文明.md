# 巴夏 66 外星人绑架与混种文明



(关联巴夏 62)

翻译：柯维

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/voqHd_gPSsE.html)

Q ：晚上好， 巴夏。

B ：你好， 日安。

Q：我的问题是关于人们认定的“外星人绑架”。

B：是的，很让人兴奋，不是吗？

Q：哦，我的问题是：这些绑架者的动机或目的是什么？尤其是对那 些被绑架者而言，真正发生了什么？

B：我可以给你一个词作为回答——我们。你明白吗？

Q ：是的。

B：你确定吗？

Q：我十分确定，在某个层面上我们都是一体的

B：不，不，不。更明确的说，你理解我来自一个你们认知的混血种 族文明 (hybrid civilization) 吗？我们就是你们称做“绑架”的基因混合 的结果之一，目的是为了使灰人的文明能够永存下去。那些被称作的“灰

人”，他们实际上并非是外星人(alien) ，他们是来自平行地球的变异人类， 他们毁灭了他们的世界，而无法延续他们的社会，因为没有可以生育的人 类 DNA 供他们使用，除非获得平行世界中你们的可生育的 DNA。

因此他们在你们的世界里打开了隧道，在更高的层面取得了同意，获 取你们的基因材料，使得他们能够在你们和他们之间混合他们的基因来创 出一个新人种，一个混血人种，而我们正是这个结果之一。因此我们在许 多方面与你们有基因上的联系，我们在许多方面正是你们的子孙，你们在 许多方面正是我们的祖先。

因此，我们认为在这项协议中，你们已经给予了我们生命的礼物，那 就是为什么我们要在这里同你们分享，无论以什么样的形式我们都要提供 帮助。因为我们正在返还给你们给予过我们的生命礼物。所有这一切都是 经过同意的，即使是许多人可能都不记得这个协定了，即使是他们可能在 某些绑架的过程中吓得要命，即使是许多灰人已经没有必要去拥有情感能 力，来理解他们已经把你们很多人吓到直喊老天爷，他们只是没有那个情 感能力了，不过，他们中的许多人已经知道了。

再次的，请理解这一切都是在更高的层面上取得了同意，许多人不明 白的是，在绑架中与他们互动的那些生物，实际上正是他们在不同现实中 的自己。所以，他们只是从你们的现实中提取了他们自己的基因材料，那 就是为什么能够达成那个协议，因为本质上你可以说是同一个灵魂。

我们是这个特别的议程下的五个混种文明之一。其实你们所说的“绑 架”，那种情况已经不常发生了。那项计划如今已到了适应新环境的阶段， 这意味着许多从绑架经历中产生的后裔，许多被那样创造出来的孩子们最 终要回归地球，生活在你们中间。起初他们会待在某些安全的飞地 (指在 本国境内的隶属另一国的一块领土) 上，最后当你们的社会接受了相关的 概念，他们就会在世界上露面。

最终大约在你们的一千年以后，在你们的星球上存在的生命只会是混

血种族。你们会成为第六个混种文明，一旦地球成为第六个混种文明，那 时所有这六个文明会开始在一起进行种族大融合，成为第七个混血种族。 简单来说就是这么回事。那有帮助吗？

B ：有帮助，谢谢巴夏。

B ：不客气。
