# 巴夏 87 关于尼碧汝行星



翻译：文森

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/uh5ZLwE_fMs.html)

Q ：你好， 巴夏。

B ：也祝你日安。

Q ： 日安。今天在这里真是非常殊胜和荣幸，我已经知道你很长时间 了。

B ：我们同样充满喜悦地与你们所有人互动交流。

Q ：谢谢。有件事情我想你能帮我，过去十年我都在纠结这件事。 B ：好的，尽管听起来更像是你可以自己帮助自己哦，说吧。

Q ：你可以帮助我自助。

B ：好的，谢谢。

Q ：嗯，我有点被尼碧汝这颗星球正向地球接近这件事情困扰着。 B ：好的，你对你所谓的“困扰”的定义是什么？

B ：是积极的还是消极的？这困扰以恐惧为前提还是以喜悦为前提？ Q ：对，这就是问题的一部分。我的初衷是积极的。

B ：初衷是积极的,但是你的行为不是？

Q ：嗯，从一些人给我的反馈来说，不是积极的。

B ：比如呢？举例说。

Q ：他们会说“我不想听你说这些”，或者是“哦，你根本不知道自己 在说什么”。

B ：好的。你能允许他们有自己的观点吗？

Q ：当然。

B ：那你能否理解，在他们所处的实相中，他们的观点实际上可能代 表了他们自己的实相？

Q ：绝对理解。

B ：你是否能理解你们全都是在各自不同的平行实相中——你们发出 什么频率的振动，你们就会得到什么样的？

Q ：能理解。

B ：那你更喜欢怎样去体验关于你所说的那个尼碧汝行星的事情？ Q ：嗯，让人们更加清楚发生了什么。

B ：停！停！停！什么意思？

Q ：我的意思是…

B ：不管发生了什么，那只发生在你所体验的实相中。

Q ：嗯，确实是。

B ：对啊，那的的确确只发生在你的实相中啊。

让我非常清楚的解释一下。我们所说的你们每一个人都处在你们各自 的实相中，这个说法并不是一个象征性说法。我们是毫不夸张、确确实实 地在说，你们都是在你们各自独立不同的平行宇宙里，各自在完全的、彻 底的、全然不同的宇宙里，这种不同是物质性的、的的确确的，真实并不 夸张。

所以，在你的平行宇宙实相中，你更喜欢什么，那只与你对那个概念 的关系有关。这和你认为你需要怎么告诉别人没有关系。你想怎样体验你 所得知的这个尼碧汝的概念？

Q ：嗯…我想体验自由。而且你知道，我想要内在更伟大的开悟。 B ：那然后呢，简单地说那将带给你什么？

Q ：享受人生。

B ：那为什么你不能就简单地直接享受人生，忘掉尼碧汝这回事？ Q ：好吧，我以前没想到这个。

B ：现在你知道了呀。很高兴我们能提供这个不同的观点。

首先，请理解对于你们中的大多数而言，在你们生命历程绝大多数的 时间线上(所谓时间线也是象征性的，不是真实存在的) ,你们不会以任 何形式感知到这个行星的物理实相，尽管这样的物理实相是存在的。所以 你们讨论的只是你们同那个想法象征性的能量连接,就如同当你们谈到宇 航时，你们以同样的方式在讨论其它所有星球与你们象征性的能量连接， 可以这么说。这些只是在你意识里的想法的投射，他们并不控制你，而是 反映你，所以你拥有了一个个工具、一个意识许可证，用来更多地学习了 解你自己。

所有的工具，所有的技巧方法， 以及所有的知识都只是意识许可证, 那允许你给予自己许可去更加成为真正的你。如果那个意识许可对你有 效，那很好。但并不一定它就对其他人也有效。但是如果你发现，你已经 知道了你更喜欢的意识许可服务于你的方式，你希望生活中能简单地拥有 更多欢乐，那么你就不需要什么意识许可证了，就去生活得更快乐就可以 了。

就这么简单。

一旦你知道了形象所代表的含义，就不必再抓住任何这些象征形象不 放了。

有道理吗？对你有帮助吗？

Q ：是的。有帮助。

B ：你觉得轻松点儿了吗？

Q ：一点。

B ：哦，好吧。

Q ：对于你刚才的回答我仍然有个问题，你说我们不会感知到尼碧汝

行星，那好，那么现在地球究竟发生了什么呢？如果尼碧汝行星不会被我 们感知到，为什么还是发生了这些事？

B ：因为你们正在经历“转变”，而且你们都同意在你们各自的平行实 相中一起体验转变。所以，因为这是一个——我就全都放在一起说吧—— 一个觉醒和转变的时代。你们正在同一切代表“由黑暗转化成光明”的象 征符号建立联系，尼碧汝行星就是这些象征之一。

这些全都是象征符号，你现在正在从这一世连接到它们来支持和协助 你——通过反映各种你们内在意识和能量的转变来一次性地决定，哪种实 相是你们所偏好去体验的。

请记住，当你们改变时，当你们所有人或任何一个人改变时，你们实 际上都会转移到另外的更加代表你们各自所作出改变的不同平行实相中。 实际上你们永远不会改变世界，你永远不会改变这个地球，这个你和其他 人栖居的星球。你通过改变自己就会直接平移到一个平行实相，这个平行 实相更代表你所偏好的振动，而且那些同样更代表这种振动的人们已经出 现在这个地球实相中了，过去那个地球会一直存在而且永远不会改变。

是你自身改变。然后带着自己平移到另一个同时性共存的平行地球， 这样的平行地球有无数个，所以，决定哪个平行地球是你更喜欢的，然后 那就是你体验着外在那个叫做“变化”的幻象。其实根本没有任何外在改 变发生。只是你把自己带入到了另一个平行实相，并得到一个全然不同的 地球的反映。

有道理吗？能帮上忙吗？

Q ：是的，是的。

B ：好的，好好玩吧。

Q ：感谢。
