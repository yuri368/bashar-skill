# 巴夏 68 混血种族的历史和人类即将面临的转变



翻译：柯维

Q ： 日安， 巴夏。

B ：你好， 日安。

Q ：我想知道你们种族的历史。

B：艾莎莎妮的历史？

Q ：是的。

B：我们是个混血种族，我们连同其他另外四个不同星球上的四个混 血种族一道被创造出来了。我们在某种意义上可以说是你们所谓的改革过 (reformed) 的种族。我们是你们和你们所说的灰人的基因工程的产物。 灰人并非是真正的外星人，他们只是来自某个平行现实的地球的变异的人 类。他们毁灭了他们的环境，变异成了你们目前看到他们的样子。

因为他们再也无法繁殖。他们想出了一个办法，就是利用另一个平行 现实的地球，也就是你们的地球上的人类的 DNA 进行了杂交工程， 以便 使得他们的文明能够延续下去。因而我们是这个工程下的五个不同文明当 中的一支，我们代表了灰人古老文明的不同方向的延续。

我们被安放到了我们的星球上，某种意义上来说，以你们的说法，我 们稍微领先了你们一点，因此，我们体验了某些你们体验的事物，然而有 很多事物是我们不曾体验过的。我们没有体验过你们在地球上体验到那种 程度的限制，因此我们能够更快的进化，当然加上我们存在于一个快过你 们十倍的频率现实上，因此你会明白，对你们而言的三百年，对我们而言 就是三千年。

Q：对你和你的人民而言一直是那样吗？

B ：再次的，在我们的文明之初，我们经历和你们非常类似的体验。 我们经历了疾病，我们以非常物理性的方式做事情，就如同你们现在这样 但是随着我们的进化，随着我们快速地统一，我们经历了伟大的提升。之 后我们很快地统一了，我们彼此间能够心灵感应。经过了那个关键点之后， 我们开始高速的发展，现在我们正从物理世界进入到非物理世界，并且承 认你们在许多方面是我们的祖先，既然我们开始更上一层楼了，由于我们 是一家人，我们很激动地同样来协助你们提升你们自己。

Q：你们第一次经历转变的时候是什么样？因为我们即将面对这种转 变。

B：极度震惊，美妙无比，欢欣鼓舞。但是我们还是有需要学习的东

西，你们一定要明白我们的社会有个“介绍人”(reference) 的存在，那个 人在我们的古代语言中叫做沙卡纳 (Sicana)。当沙卡纳这个人出生以后， 他在三天之内就将我们所有人以心灵感应的方式联合在了一起。如果那还 不是震惊的话，我们就不知道还有什么是了。

在我们的历史中，我们经历了一定的时间适应了心灵感应，但是最终 我们理解了通过活在当下，允许同步性作为我们的指引，之后一切事情都 在完美的时机，完美的地方在最恰当的人身上发生了，而一旦我们认识到 了那就是生命作用的方式，我们就顺其自然，乘上了潮流。我们没有与之 对抗，我们还是会发现新事物，我们的社会中依然有一些我们不期而遇的

事情发生，你们可能叫做意外，但是我们知道真的没有所谓的意外了，不 过我们依然从中学习，我们依然会遇到许多让我们着迷的神秘事物，我们 在不断地探索，学习新的事物，就和你们一样。

Q：你是否可以给我们一些信息，关于怎样进入或者更好地理解这个 新时代？

B ：我已经给了你正确的准则，也许你没留神。

Q：不，我只是想知道还有没有额外的什么，你还想附加点什么吗？

B ：真的没有别的了， 以你最高的兴奋去行动，发挥你最好的才干， 每时每刻都那么去做，直到你再也无法深入了为止，对结果毫无期盼 (零 期盼)，那就是准则。现在如果你想要在附加点什么，让事情复杂化，当 然可以，随便你啦。但是就是那么简单，然而，我们理解因为你们许多人 在你们的星球上被养大的方式，你们认为简单是非常困难的。

Q ：证明一下。

B ：“事情太简单了似乎就没有价值”，那就是个定义。我们对这个观 点不买账，你们也不必。但是你们相信那个观点的话，我们也不会强迫你 们改变你们的想法或做事的方式。我们只是在这里反映给你们可能性、选 择和机会，你们也不必一定要接受，我们是如此无条件地爱你们。我们允 许你们感到自己不是被无条件地爱着的，那就是我们有多么的爱你们。所 以如果那是你们的选择，我们支持你们。然而如果你想要允许事情容易些， 允许事情简单些，走上一条阻力较少的道路，那就是准则了，那就是全部 了，再无其他什么附加的了，除非你们想要再加上些什么让事情更复杂一 些。

Q ：太好了，谢谢。

B：对你有帮助吗？

Q ：帮助很大。

B ：谢谢。

Q：我还想要知道你们的种族同 Iris 有怎样的关系， 以及我们正在经 历的转变。

B ：哦，就如我们说的，我们正从第四密度进入到第五密度，而你们 正从第三密度进入到第四密度，我们以我们自己的方式一起向上演化。

Q：还有其他生命也那样吗？

B ：当然他们也是。

Q：是每个人吗？

B ：许多存有在以不同的方式进行扩展，有一些似乎是走向岔道、沉 降下去、失去连结，然而那仍然是全部的体验和学习的一部分。

Q ：太棒了，谢谢。

B ：谢谢。
