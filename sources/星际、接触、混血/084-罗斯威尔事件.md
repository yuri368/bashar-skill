# 巴夏 95 罗斯威尔事件



翻译：爱人的心

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/UIoLmC6U2GY.html )

Q：在 1947 年罗斯威尔坠毁的真的是一艘外星飞船？还是只是一颗人 类的气球？

B ：那是一艘外星飞船。

Q：啊

B ：其他任何别的说法只是一些障眼法。

Q：啊哈，那么最近政府公布的一些气球碎片神马的也是进一步的掩 饰了？

B：这是这个议程的持续动作， 目的是为了保证外星人存在这个消息 在受控的模式下融入你们的社会，这在运作这议程的那些人认为是恰当 的。

Q：好的，谢谢。那艘飞船来自什么文明？什么导致的坠毁？还有一 些问题：我们现在的地球科技是否有一部分来自对这些飞船的反向工程？

人类要想在太空中像外星人那样自由飞行，需要掌握哪些知识？

B：好的。这样的生命虽然有很多，但在那次，也是首次坠毁的飞船 中的生命，是混血杂交人种和我们社会(Bashar 所在的社会，Essassani) 的生命很类似，但不是来自那里。那次坠毁起因是闪电，闪电击中飞船， 干扰了驾驶机制。数具尸体被发现，有一个当时仍然存活，但最终死掉了。

Q：他存活了多长时间？

B：好几年...现在...地球人曾经试图对坠毁飞船的科技进行反向工程， 并且取得了一定程度的成功。飞船上的一些技术被获得。其中有一些已经 进入了你们的社会，但是没有你们想象中的多，因为很多你们科学家从飞 船上发现的科技，远远超过了地球人的理解能力，有一些东西至今人类也 不了解，因为他们没有完全弄清楚 (这回答了你最后一个问题) 怎么像我 们一样穿行宇宙；他们没有完全懂得我们怎么在我们的技术里运用我们的 意识。

飞船是有知觉的。它们是有意识的生命体，直接和飞船成员或者说是 驾驶员在意识层面上连接。而且还有其他技术，比如说怎么制造这样的飞 船，怎么共鸣，怎么识别，怎么“重定位”。这些科技可以被意识本身最 有效的引导，指挥，因此，当你们的科学家开始越来越多地发现这些科技 与意识间的关系之后，当他们真正地创造出人工智能以及有自我意识的电 脑后，你们才真正踏入复制或者镜像你们所回收的飞船里的科技的大门。
