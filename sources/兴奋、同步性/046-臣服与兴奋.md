# 巴夏 61 臣服与兴奋



翻译：觉醒者校对： 尚林

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/XnwirfbCXIs.html)

B：臣服，放下。(Surrender.Letting go. )

我们明白，你们星球上有很多关于“臣服”的定义，你们很多人会把  它视为某种“损失”或类似于某种“失控”。不是这样的。现在，我们想  提供我们对“臣服”的定义，那就是放掉“你认为你应该成为什么样的人” 的那些概念和想法，并成为真正的你，因为真正的你是无限的可能性。当  你允许自己臣服于“你是以无限为原型受造的”，这意味着你也是无限可  能，这时，作为“镜像”的物质实相，就会将无限可能性同步反映在你的  日常生活中。 因此，“臣服”实际上是接纳你的全部自我，而不是摒弃你

的全部自我，而不是你们很多人被引导去相信，“臣服”这个词是用来限 制你们的。这就是我们想要与你们分享的，并建议你们学会“放下”(give up)。

Q：放掉那些限制吗？

B：你的最高喜悦，对你们来说都一样，就是以你所知的方式来尽可 能地做你自己。跟随和实践你的最高喜悦，并不需要有多神秘，多复杂， 也不一定非要是一个终生事业或者项目。从简单处开始，如果你不是很自 然的在心中就有大的事业项目等，你可以断断续续的开始，跟随自己的最 高喜悦，它会为你揭示更多的喜悦。

在每时每刻，你都有多种选择去做不同的事，不是吗？你只需要选择 那个最让你兴奋的事，尽量去做就是了。你只需这样做就够了。下一刻， 再评估一下：在此刻这种环境、情况、方向中，在我所有的选择中，哪个 包含着我的最高喜悦兴奋，当你决定了是哪个时，尽你一切的可能去做， 直到你无法再继续。然后再次问自己：我现在所有的可选项中，我的最高 喜悦兴奋在哪个方向？找到了就尽力去做。就一直这样重复，度过你的余 生。因为，兴奋就是那条能把你引向其它兴奋的线索，就是能让你做回你 自己的能量。

这点很重要哦，很重要哦——别在意(Regardless)， 别在意那看起 来如何，别在意你认为那和你“应该”去做的事有没有关系，别在意外在 世界的表象，因为你已经知道这不能用表象来判断。兴奋才是让你明白“此 刻这样，才是真正的你”的见地。去做它吧！(Doit!) 因为，通过跟随你 的兴奋与喜悦，你就是在向宇宙坚定的宣告“这就是我！”这样，宇宙才 能支持真正的你，而不是去支持你被教导成去做的那个你。

这里，有件事你必须注意，因为我们知道你们是怎么被灌输长大的， 我指的是你们所有的人，不是仅针对你，你必须诚实的看自己，究竟是在 体验兴奋还是焦虑？ 因为有时，你们很多人说“啊，这个使我兴奋”，但

其实你们真正在做的是逃离自己的兴奋。你实际上是在跟随某些源自焦虑 的事情。但只要对自己诚实，你们都能知道二者的差别之处，因为你们清 楚“兴奋”与“焦虑”的感觉是不同啊。

实际上兴奋和焦虑也是同一种能量。你的身体以“兴奋”这种生理感 受所体验到的，是你的自然能量。当你让你的能量，你的自然能量，流经 与你的真实自我和谐一致的信念系统时，那种能量被你的身体当成一种 “兴奋”的感受来体验。当你的能量，流经与你的真实自我不谐调一致的 信念系统时，这种非常相似的能量被你感受为焦虑和恐惧。而这也是恐惧 存在的原因，它来告诉你——“嘿，你在感受恐惧!因为你的能量所流过 的信念系统里的定义，与你的真实本然自我并不谐调一致”。所以，找到 那些定义是什么，把它们换成你内在真正偏好的定义，让你的能量流经它 们，这样，你和你的境遇就会和谐喜悦地共存。这样你也会以和谐喜悦的 方式来接近这种状态，并且从这种方式中得到和谐、喜悦的感受。

最令你兴奋喜悦的事是(注意听好) A： 统御性法则 (organizing principal) B：做出决定的驱动力(the driving engine that determines) C ： 还有哪些事需要去做。

当你尽力做让自己最兴奋喜悦的事时，首先，你的一天将会自动重组 和排列，每一件事都会是让你兴奋喜悦的、同时你又有能力去做。到了一 天结束时，你还没有机会和时间去做的事，就是这天你不需要做的。因为 当你以这种方式运作时，令你整体运行的所有真正对你重要的事，以及完 成你真正需要去做之事所需要出现的一切境遇，都会恰到好处的出现，并 完美嵌入不同的时间点、时间线，来使你以轻松地、创造性地、诗情画意 地、同步巧妙地体验这一切，而不是去忙乱的完成它们，——某种意义而 言，那只是你的人格架构被灌输从而认为你需要去做，它是你认为“你是 谁”的一种派生表示。
