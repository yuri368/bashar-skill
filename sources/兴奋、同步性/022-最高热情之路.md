# 巴夏 20 最高热情之路



(2009 年 11 月 4 日)

翻译：早起    校译： 尚林    整理：风总是吹

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/_r0ZiotL4Sk.html)

Q ：这是我第一次和你交流

B ：这也是我第一次与你交流啊，恭喜哦！

Q ：谢谢！我有一个小小的问题。

B ：没有哪个问题是“小小的问题”。

Q ：哦，听你这么说太好了。

B ：谢谢，这个问题对你而言重要吗？

Q ：是的。

B ：为什么你认为它是“小小的问题”？

Q ：因为我觉得他们每个人提问的主题都很大，

B ：比如关于宇宙之类的大问题？

Q ：是的，所以我......  (笑)

B ： 日常现实生活中的问题，和任何其它问题一样，都具有灵性的意 义。你了解吗？

Q ：是的,谢谢。

B ：任何问题，都拥有同样重要的灵性意义。而如果有一个问题对你 来说是重要的，那么它就不是“小小的问题”。

Q ：谢谢。

B ：好吧，你的问题是什么呢？

Q ：我的问题是：我有一份工作，但我想知道它对我的意义何在？要 多久才能从这份工作中解脱，去创造我真正想要和喜欢的生活？

B ：通常，我们探索这类问题的方式是，提出一个问题令你思考，而 不是研究你所说的那个小小的问题。我们要问你的是：“你在做最能让你 兴奋喜悦的事吗，有还是没有？ ”

Q ：没有。

B：谢谢你的诚实。下一个问题是：“那么，什么时候你才会选择去做 那些能让你热情四溢的事情呢？ ”这是一个更大的问题。

Q ：我很想昨天做这个选择，但……

B ：可是你并没有。这是因为......是怎样的信念系统阻挡了你呢？ Q ：恐惧。

B ：恐惧什么？

Q ：恐惧什么 …

B ：对，你恐惧什么？

Q ：恐惧我所选择的无法带给自己真正的快乐。

B ：你的意思是：如果你选择那些能激发你热情的事，你所选择的可 能并不能真正令你兴奋？ (如果你根据现在的愿望选择那些能激发你热情 的事，却又担心你所选择的可能并不能真正令你兴奋？ )

Q ：对我的挑战是，选择做自己兴奋的事情，因为它对我来说...... B ：为什么说这是个挑战呢？这是容易的事情啊。

Q ：好吧，是的。

B ：你相信这很容易吗？显然你不信。

Q ：我不相信。

B ：好吧，我来解释一下，让你看到它其实很简单

Q ：好吧，请说。

B ：好的,谢谢。你们"新时代"意识运动中，很多都提到“跟随你的喜 悦 (bliss)”、“做令你兴奋的事”，但常常对此没有清晰地解释：为何要这 样做或者如何去做。

要明白：首要的、以及最重要的极其简单的方式就是——“跟随”。 当我们谈到，任何时刻都要“跟随你的喜悦和最高的热情”时，我们并不 是指，一定要做一生的职业规划，或者是一个具体的计划，或者一定要全 力以赴。我们真正确切的意思是：在生活中的每时每刻，在你可以选择的 范围内“跟随你的喜悦和最高热情”去行动。虽然这些可选择的事情中， 有很多在你看来可能只是琐碎事，但你仅要做的就是：在每时每刻，在你 所有可选择的范围之内，都去做能带给你最大热情的事。句号！就是如此 而已。非常简单。热情是一条线索，它会引领你经验其它的热情！

所以，如果你仅仅坐着想：“噢，我不知道什么才能让我热情高涨”。 请看看你面临的选择，列出当时你拥有的各种选择。也许当时的选择只有：

购物，去海滩散步，或给朋友打电话，只是打个比方啊，那么就选择最能 让你动心的那个去做，同时，全心投入并尽最大能力去做这件事，做到极 致。当你来到下一个选择路口，还是看看你有哪些可选择，然后挑选那件 自己最热衷的、最得心应手的事情去做、去行动，当你来到下一个十字路 口，依旧如此，当你又到达下一个路口，依旧如此…

你所跟随的热情，会自动把你牵引进一系列的同步事件中，这样会持 续地加速和拓展你去经历热情的能力。同时，也会不断地加速和提高你去 经验到你的热情将能支持你在现实生活中安身立命的能力——如果你在 这条跟随热情之路上持续前进的话。以上说的这些，你能理解吗？

Q ：是的。

B ：那么，现在的问题变成了：你相信它吗？

首先，我们提出的是：“在任何时刻你需要做的，只是从你的可选项

中，挑一件相对来说比较想做的事情”、“如果你想不出能令你绝对兴奋的 事，那就只在当下的可选项中选择。”、“当你感知到某件事能带给你热情 的时候，就从中挑选那件事去做。”

我们知道，当我们给出以上观点时，通常，人类头脑里马上会跳出以 下这些问题：“可是我想做的那事跟手头这件无关啊”、“那怎么会有利于 我？ ”、“不能理解”

但是，你没有必要去理解它，这恰恰正是美妙之处。你要知道，你的 物质心智(physical mind) 不是被设计用来理解“事情将如何发生”的， 过去不是、将来也不会是。物质心智无法理解：仅凭跟随热情，是如何把 你所需要的资源完全地带给你的。所以你没必要考虑它将如何发生。你需 要做的，只是相信它会自动发生，并且去行动。因为人类的物质心智，是 为了去经验正在发生的事情而设计的，如此而已。

人类的头脑、这个物质心智，仅仅是被设计用来感知和体验的。事情 运作的机制、资源到来的途径，都是由更高领域掌控。这些都已经超出了

物质心智所能领会和理解的范围，也不可能被物质心智完全地知晓。

所以，你的物理要停止做高我的工作，而让高我去做原本属于它自己 的工作，让高我根据你的需求， 以对你最有益的方式为你带来各种资源。 所有你需要去做的，就是启动这个高我的运行机制，我们明天会更详细地 说明关于高我的显化机制。你所需要做的唯一一件事情就是：开始把球滚 起来(启动高我机制) ——通过跟随你的热情、去做你力所能及的事。

而当你开始这么做的时候，你就向高我证明了：你愿意朝这个方向前 进。然后高我就会引领你更进一步。最后，高我会愿意引导你，进入更高 振动频率的行动，以便你能反馈给她更高频的状态、更多代表高频振动的 事物。高我会以此方式来显示她乐意帮助你。

但如果你不愿意跟随你的热情去行动，你的高我又何必给你资源呢？ 你看，你得把你不擅长的事情挪开，腾出空间，这样更大的事物才能进来。 因为如果你并没打算以目前所拥有的资源去跟随你的热情去行动，那么， 高我不会去做那些毫无意义的事情，或带给你新的资源。如果你不跟随热 情行动，你就是在阻碍这个过程，阻碍自己拓展热情的机会。能理解这个 机制了吗？

Q ：能。

B ：你是否愿意相信——只要跟随你的热情，它会自动把你带到你要 去的地方？

Q ：我愿意。

B ：相信各种事件会同步发生，好吗？

Q ：好的。

B ：我们等着看你的表现哦。

以上这些，只是对这个机制如何运作的基本解释。所以，当你说你觉 得寻找自己所热衷的事情很困难，我得抱歉地对你说，我们并不相信你所 说的。因为这 (跟随你的热情) 真的比你思考本身更简单，你现在只是对 “热情”和“跟随”的概念有点不清晰罢了。明白吗？

Q ：我明白了。我想，我那个问题的另一方面是：我觉得我现在的工 作环境，并不能激发我的热情。

B ：那就离开它啊！但是，要知道：我们都非常清楚，你们许多人都 受困于自己的信念系统 (belief systems)，你的信念系统让你认为：如果离 开这个工作环境，你很可能找不到自己热爱的事情，或者如果离开这个工 作环境，你必然要承受压力。那么这种观念就真的可能令你体验到苦难的 情境。你必须尊重你的信念系统，只要你还依存于它。但至少你可以采取 任何目前你可以采取的行动，至少你可以做任何你愿意做的，能让自己喜 悦兴奋的事情。而当你跟随喜悦做得越多，你的热情也会让你看到它能支 持你；而它让你看到的支持越多，你也就越愿意去放下你不喜爱的东西了。

所以，你尽可以遵循自己的步伐节奏，但不要轻视你的信念系统。你 可以跳下悬崖，但只有当你相信你真的能飞的时候，否则，我还是建议你 安全着陆。因此，请不要轻视你的信念系统，不要简单地想：“好吧，我 才不管这么多，什么信念系统，权且孤注一掷吧”。这样会让你四处碰壁 的。关于这点，我们明天还会继续谈论。

当你清理信念系统时，你需要明白：为什么会有这样的信念？还有， 在那些你既喜欢又不喜欢事情上，你无法被支持。当你在认清自己的信念 上下功夫时，你就能转变它们。

当你越多地改变你的信念系统，你就会 (对热情) 变得越放松，越信 任，而不再执着于知道：到底热情怎样支持了我？

有一个强有力的例子，我经常向你们推荐。因为它完全基于你们的现

实，所以更容易在你们的头脑中扎根。你不妨去看看你们世界中的这样的

一些典型人物，他们其它事情都不做，就只做那些最令他们热情喜悦的事 情，仅此而已，他们也能够安身立命，事实上，他们在过着相当精彩的生 活。

我向你保证，当你能看到并理解他们的作为，你也同样会明白——他 们能做到的，你也能做到，因为他们并没有什么特别的背景。而如果你能 看清楚，如果在你的现实生活中能出现这样的人，他们仅凭喜悦和热情做 事，便能以此为生，如果你的现实中已经出现了这样的例子，甚至如果你 仅仅只是察觉到了有这样的生活状态，这些事实都意味着，你也有能力这 么做。否则的话，你是没能力觉知到这一点，因为现实中不会出现无意义 的事，你也无法察觉到那些你的潜在频率仍未到达的状态。你明白了吗？

Q ：明白了。

B ：这对你有帮助吗？

Q ：是的，非常感谢。

B ：谢谢！！这真让人兴奋！~~
