# 巴夏 53 兴奋与一个大秘密



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/UT7FN7BYhwo.html)

Q ：我有个关乎个人的问题。

B ：我觉得每个问题可能都是个人的问题，因为是被一个人问的。

Q：我如何才能知道下一步应该做什么？

B：我告诉你了的。你注意了吗？你能否自己回答这个问题？

Q ：不能。

B ：在无论何种被给予你的、包含着最多兴奋喜悦的、你有能力去对 其行动的境遇和机会中，尽你所能地去行动，并且不要对行动的结果有任 何期望，设限。在任何时候都这么去行动。比方说，你今天选择了来这里 这场互动对吧？是因为这让你兴奋吧？

Q ：是的。

B ：那么接下来你要选择做什么呢？随便那是什么，在一切可以选择 的选择里，首先选择和实践那个包含最大兴奋喜悦的，即使那件事看起来 和其它你称为“兴奋”的事没有关联。因为，无论什么，只要包含最高兴 奋喜悦，它就是联系你人生中其他会令你兴奋的事的那条线索，无论它看 起来是什么样的。

所以如果你一直这样做：看一看，我现在能做的事情中，最令我兴奋 的是什么？哦，去沙滩散步。好，去吧。现在我能做什么最兴奋的是？和 朋友吃顿饭。好，行动。现在我能做什么最兴奋的事？看书，啊，好的 …… 就一直这样做，它自己会积累和扩张，并且将你带到可以不断扩展的境遇 与情况中，直到你的人生里全是让你去做兴奋喜悦的事的机会。说清楚 了？

Q ：是的。

B ：那就是下一步。那就是第一步。那是你需要走的唯一一步，因为 兴奋都是一条线，它们会将你引向其他兴奋。并且兴奋就是你生命的原动 力和统御法则。如果你一直实践它，它会在你需要的时候带给你需要的一 切。

现在，我要告诉你一个大秘密！你不需要一个特定的理由去实践任何 事情，你唯一需要的理由就是：那是你偏好的，那是你想做的。在造化万 有中绝对没什么要和你作对。这让你觉得自强自立了吗？

Q ：是的。

B：那很好啊~
