# 巴夏 77 信任你的喜悦



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/lGE0CCIWeV0.html)

Q：你好巴夏！

B：你也日安！

Q ：我先感谢你在过去几年中给我的很多帮助。

B ：我们感谢你帮助了你自己。

Q：现在由于我开始面对自我…

B：你喜欢你看到的吗？

Q ：是啊， 比之前喜欢。

B ：好吧， 比之前喜欢。

Q：嗯~探究我经历的事件对于我的真正意义是什么。

B ：记住，某个事物对你来说意味着什么，这取决于你对它赋予怎样 的意义。意义并不是本来具有的。(Remember that what it means for you to play is determined by the meaning you chose to give it.The meaning isn’t built in. )

Q：我注意到通常这牵涉到活在当下 (being in the moment)。

B：通常~~~是的。除非你在选择“不在当下”去玩。那是唯一的例 外。

Q ：是的，我发现了这点的。

B ：哦，谢谢。

Q：那么通常地~~~

B：是的，通常的~~~

Q ：这包括我对自己信守承诺，我给出承诺然后信守它。

B ：是的，只有你可以给你自己理由不去信守。但然后你又在信守另 一种承诺。记住，你永远不是真的没有信守承诺，只是有时你变化了你信 守的承诺。你永远不会不信任，你永远不会无信心，你永远不会不守诺。 你只是变化你信守的内容而已。决定你想要信守的内容是什么，然后信守 它。

Q：我也注意到了我的……。

B：通常地~~~

Q ：不，不是，我是说当下。

B ：哦，好吧。

Q：我的左眼变得更大更亮更清澈了，但以前我经常眯眼并且眼会红， 而且经常头疼。因此我设想这应该是我开始使用我的右脑的反映。

B：你这样假设是因为？

Q ：因为你以前告诉过我，我应该使用我的右脑。

B：好吧。但是那不是你要这样假设的原因。并不是因为我告诉你要 这样。

Q：你说过我的？在左边循环……

B：那也不是真正的原因。你这样假设是因为—— ？这不是个考人的 问题哦。这样设想是因为你偏好于这样设想。

Q ：哦，好吧。

B ：很简单，不是吗？看，没陷阱。

Q ：那就不是原因。

B ：我已经告诉你了那就是原因。

Q：哦，好吧。那么我有个问题关于……我最大的热情是与动物交流， 并且照顾它们。尤其是照顾我自己的宠物。

B：好啊。然后呢？你开始基于这些热情行动了嘛？

Q ：通常吧。

B ：“通常”来啦。好吧，我知道它会在某刻冒出来的。

Q：但你知道的，那些照顾动物的日常工作是……

B：等一下，等一下。如果可以我想提醒你—— 即使我明白，跟随你 的激情不见得完全会让你一直得到一样的机会去做一模一样的事——但 是，我要提醒你，一般来说“强烈的”(Fervent)，“热情”(Passion) 这些 词和“通常地”(Usually) 不共存。如果那是“强烈的”“热情”的话，那 么那就会是“一直地”(Always)，而非“通常地”。你明白我的重点了？

Q：我如何能重新定义那种劳苦…

B：啥？

Q：劳苦，有些时候感觉是这样…不是所有时候，有些时候我感觉照 顾宠物是一种苦差事。

B ：把什么定义成苦差？因为这是你给它的定义。

Q ：清洗笼子啊，清理便便啊之类的事情，你知道的就那些事。 B：为什么那是苦差事？

Q ：有时候这些事不是苦差，而是很好玩。

B：那为什么它有时好玩，有时又不好玩？

Q：是啊，这就是关键所在！

B：是的， 回答我的问题，为什么同一件事有时感觉好玩有时感觉像 是苦差？当你觉得好玩时，你的内在是怎样的？那和你觉得不好玩时有何 不同？

Q：嗯~有时就是觉得干其它事更有意思 …

B：不是这个原因。当你如常觉得那好玩时，你的内在发生着什么？ 当你不觉得好玩时你的内在又发生着什么？ 区别在哪里？那种你内在动 力的真实区别是什么？你感觉有趣时和不觉得有趣时，这两种情况下，在 你的定义当中，你的能量形态当中，你的信念当中，有什么不同？

Q ：我偷懒了。

B：那是啥意思？

Q ：我就是不想做那个。

B：为什么不？

Q ：我想偷闲，我想去给草地浇水而不是照顾宠物。

B：为什么那个是很闲适的？为什么那个是很闲适的？

Q：哪个？给草地浇水？

B：对！

Q ：我觉得那更有趣好玩。

B：为什么？为什么？

Q ：它一直都好玩。

B：为啥？

B ：好吧，我这样问你吧。你是不是觉的，那时如果你去给草地浇水， 动物们就会被忽视冷落了？

Q ：有时，是啊。我觉得那时我应该喂它们，我却没有去喂它们。 B：好的。你知道你为什么会有这种分裂嘛？

Q：为什么啊？

B：因为，你在不同的代表你喜悦的事物之间刻意地创造了分裂对立。 也就是说你不信任。如果你的喜悦的确移动到了另外一个行为上，却又代 表其它事被冷落了，这表明你不信任自己的喜悦。

Q ：的确如此。

B：那么为什么你要有那种定义？

Q：这牵涉到我另一个问题。你有一次在这说过，如果你实践你的喜 悦，不管在一天结束时如何(你有没有做完每件你觉得要去做的事)，其 实你已经做完了那天实际上需要做的事了。

B ：是的。但是如果用你去对待这件事的方式，是不会允许时机自身 同步巧妙地重组的。因为，你给自己正在做的事情，设下了一个特定的框 架。如果你真的信任你的喜悦的换位，那么一切都会重新排序组合它自己， 来让你在正确的时间里，喜悦地做你真正需要做的事。

Q：如何看待这种情况：当你在做一件兴奋的事时，突然你的兴趣又 转移到另一件看似更令你兴奋的事上，但那时你还没完成手头那件事。

B ：你没听我刚才说的。我再说一次。如果你懂得如何去信任你的喜

悦，那么你会知道并体验到，当你的喜悦换位时，它会创造出其它时间令 你能喜悦的去做另一件事。你觉得不会这样(以后另有时间去喜悦的做它) 的先入为主的想法，才是让你体验到那种分裂的原由。

顺便谈下巴夏最后这段话我觉得重要的地方，也是很多人经常问巴夏 的矛盾点。很多人在担心如果我跟随喜悦去了，其它事怎么办怎么办 (时 间，资源的有限)。巴夏说的是，你真的信任你的喜悦的话(包括信念体

系的转变，指真的信任，而不是信念体系还没变过来那种假信任)，这些 怎么办怎么办是不会出现的，而不是出现了然后没法解决。因为内心的态 度发生变化后，时间线，时空点已经开始重组了，你会吸引不同的时空要 素 (时间，资源，运气) 来让你免于陷入“怎么办”的困境中，进而被支 持继续去喜悦兴奋。这就是他说的 synchronicity 的意思。
