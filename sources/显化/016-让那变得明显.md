# 巴夏 45 让那变得明显



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/LpN6Jj4iCng.html)

让那明显起来，让那明显起来。诉诸显而易见的态度。再次，再三， 我们就是无法把这句话说够：那就是那么单一！当我们说“那就是那么单 一”的时候，留意，无论你的物质思维有没有讲这句话当成了一种比喻。

很多时候我们说那就是那么单一，人类认为我们的意思是“那个的难度简 单”。那个的难度是简单的，但是这里我们真正的字面意思是，那就是： “创造就是那么本质单一”。一切事物都是同一个东西！( creation is that simple!It’s just one thing!)

万物造化的本质已经单纯到了无法更单一的地步。那么以这个单纯的 本质则派生出了一切丰富的多样性。但是这个多样性本身并不代表它的本 质是多样复杂的，只是那个单纯的本质在与自身进行着非常丰富的反映性 互动而已。但根本上说，一切复杂性，一切丰富多样性，都源自同一个单 一的本质。

所以尽你一切地可能看单纯点，因为一切本质本来就是那么单纯。我 们理解因为你们大多数人被教育的方式让你们觉得难以相信事物的单纯 性。因为你们被灌输了大量的信念体系。像“不劳无获”、“不经历风雨， 看不到彩虹”诸如此类的观念。再次的，不是说你们就不能享受神秘，挑 战与探索的乐趣，也不是说你们不需要发现新事物。但是这一切都可以是 很享受，很好玩的！如果你想要的话，都可以得到！无论对你们所谓外在 世界还是内在自我的探索。这些都能把你引向无穷的宝藏！因为你本身即 是百宝箱，你拥有的宝藏珍品甚至超越了你的这个物质思维的想象极限。

当你允许自己一直认识到其本来的单纯，那么你就会被赋予拨云见日 的纯然喜悦，以及来自于向自己和他人展现自我，来允许他们也获得单纯 的反映和单纯的喜悦，那将令他们明白他们也不必挣扎，不必奋力，他们 也可以去挑战自我，去探索和发现，但却不必以任何形式受苦受累去做到 这些。现在已经不用，而且再也不用那样了。

就算在过去你们的“集体无意识”的确共同协定过那受苦受累，是这 些在过程里必须的，但是在今天这个时代，你们已经通过你们的“集体无 意识协定”决定，这也是现在在地球上，我们能够开展一个像这样的讲座 来向你们传述和提醒这些知识理念的唯一原因，它就是：在你们的“集体 无意识协定”里，“受苦”不再是必须的了。现在你们的“集体无意识协 定”里已经包含了在日复一日的喜悦中去体验自我和生活的选择了。这是 你的权力和选择，只要你想，就可以这样做。

我们能够来探讨这个的唯一原因就是你们决定了如此。如果你们没做 这种决定，我根本无法在你们面前开口说出这些，实际上很可能我们根本

无法跟你们说上一句话。因为那样的话，我们仍然还会在离你们的实相相 当远的地方，在你们能够接受的可能性之外。

看看此刻这里正发生着什么。虽然你们不一定要以你们的物质实相思 维的方式，去验证性地相信我是一个以心灵感应方式，通过你们物种之一 的他作为翻译机而与你通话的外形意识，但重点仍是如果现在这场对话已 经在发生了，那就表明了你们正开放自己去体验这些，表明了你们已经处 于你们所选择的存在状态。而且就算我是外星生命这件事不是真的，这种 通灵状态本身也是真的！就像我们说过的，即使物质实相并不是验证性地 绝对真实，但由它而来的感受体验却是真实的！所以，开放自己，允许“一 切万有”通过你来彰显自己，以其所需要的任何方式或形式来代表你的真 实性，你的确信，创造力，喜悦和对自己的爱，让它这样发生吧！

让那变得明显起来。让你自己做回你本来明显被造化的样子。然后， 你就能感受到造化万有以无尽无条件的爱把你激荡而起，携你畅行，让你 在生命涌流中轻松喜悦地舞蹈出璀璨绝妙的交响乐章。

那其实才真正更接近你的本真，而不是上万年里你一直执取的那些关 于你自己的概念。你是光，你是能量，你是音乐，你是声音，你是波动， 你是振频，你是共振，你是意识，你在以一切可能的方式与自己互动。你 们彼此分享着，彼此分享着一个交汇点，以体验到你们正在一起跳着一支 美妙壮丽的舞。那个交汇点一下创造了你们所有人。并且你们中的每一个 个体都是其它每个个体和大家一体的一面镜子。让那个镜子照出你显然本 有的神性。这，就是一切。

一切即是神圣以自身能够的一切方式表达着自己，表达着你在其中的 位置，你在其中的彰显。一切都是同样的美丽，同样的有效、有价值，同 样的平等。创造中的一切造化彰显都是相互平等的，在每个面向里都是同 样的平等，美丽，有效且珍贵，而又独一无二。虽然独一无二却又是相互 平等的。一切澄澈显然！这一切对我们来说都很明显，关键是允许它对你 们也变得显而易见、理所当然。
