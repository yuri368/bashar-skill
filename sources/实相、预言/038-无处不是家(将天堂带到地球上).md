# 巴夏 37 无处不是家(将天堂带到地球上)



翻译：Deepcall        整理：风

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/o53Ad8KIoZk.html)

B ： 问候！你们好！

Q ：我一直很好奇，他们 (我的孩子们) 来自何处……因为…… B ：他们来自地球。

Q ：那么他们 ……

B：他们是不是你的孩子？  (是的。) 我想告诉你的是，这些问题—— “我来自何处”“他们来自何处”，在形而上学的学问中，真的是一种极为 过时的理解。你来自灵 (sprite)。如果你想要有一个具体的起源，那么， 你来自“一切万有”(All-That-Is) 的源头。

但当你问“我来自哪里”时，你是在指另一个实相、另一个维度、另 一个星球、另一个文明。我的回答是：你是来自地球，因为它是你在物质 层面上出生的地方。而你真正想问的是——既然所有的生世同时存在着，

既然万事万物同时存在着，你怎么可能从任何其他的地方到来此处呢？ 你能明白吗？

Q ：是的。

B ：你选择、你的超灵魂 (oversoul) 选择扩展自身，因而在同一时间 投胎成为地球上的生命。这个超灵魂在其他面向，其他的地球生世，其他 的文明以及实相的其他领域中亦拥有其他的自身扩展，而它们同时存在 着。所以，当你问及“我来自何处时”，其实换句话说，用更加现代的语 句来表达即是“此时此刻，我的这个生世，在与哪些同时存在的其他实相 连接着，与哪些服务于我，助我定义我此生选择要探索的主题的实相连接 着？ ”这才是你真正所问。

因为你不是来自所谓“过去”之中的任何地方，你现在正横向连接着 所有的生世。它们服务于你的这一世。与此同时，你其他的生世也都在做 着相互的横向连接，它们与你此生的经验相连，来帮助、协助它们自己。 它们“下载”一些可能与他们的生世之经验有关的信息，这一切在同一时 间进行着。(注：你也在下载，相互下载) 能够明白吗？

Q ：是的。

B ：所以，在你们对灵性和超自然学的探索之中，这是现在我们对你 们世界的协助之一。事实上，你们的某些定义在很多方面已经非常过时了， 由于你们设计问题的方式，由于你们设计观点的方式，那些定义本身就会 让你们的内心产生困惑。例如问道“我来自何处”。当你理解“万物皆存 在于同一时刻”时，那个问题就变得毫无意义。你会理解，你来自此刻- 此处 (hereand now )，你会理解，你能觉知到的其它地方，是因为你变得 更能觉知那些存在。而当你问及“我来自何处”时，那只不过是由于你的 意识扩展到了一个程度，使得你变得能觉知到那些你与之相连的地方所 致。

你们很多人以为，当你们做出那个连接、当你们实现了那种连接时，

它似乎就意味着你们是来自那里。它真正意味的是你正变得越来越能觉知 到你与那个地方的连接， 明白吗？  (是的。) 但既然你已选择此生投胎地 球，那么，与那些与其他地方相连接的意义，都是为了让你更加觉醒，更 加意识到那些你从其他同时存在的平行生世中提取来的与你相关的信息， 并让你更有意识地去使用那个信息、使用那个能量，将它带入地球。这就 是在这个转变时期里，你要如何协助 (扬升进程) 的重点。

因为，当你谈及“我来自何处”时，就会制造困惑，使你们许多人感 觉到好像是应当离开地球、回到“家乡”，真相是：无处不是家。(homeis everywhere) 你是永恒的，你是无限的，你就是“全是”与“全在”。你 所在之处即是家。所以，如果你将你的定义合理化、现代化，那将不是关 于与地球分离、以试图去到某处，或重新连接到你认为你来自的地方——

那些你判定为比你所在之处 (地球) 更好的地方——而实际不是，它们只 是不同罢了。

因此，通过将一切平等化(齐物)， 并知晓那是与此世同时存在着的 连接，你就可以应用那股能量去带来那个振动。如果你更喜欢那个代表着 其他生世的振动的话，你可以通过自身将那个振动带入地球，并将其作为 “你”在地球上的版本，以那个方式——那个其他的连接，那个其他的生 世，那个其他的存有之方式去生活。而由此，得以让全世界将你看作一个 活生生的例子，一个能量的投射，让他们明白自己亦可以做出这样的选择。 这样说能明白吗？

Q ：能。

B ：这对你有帮助吗？

Q ：是的。

B ：谢谢^^

Q ：谢谢！
