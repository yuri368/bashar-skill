# 巴夏 169 未来社会的无政府管理



翻译： 尚林

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/XGsv-oRXt-s.html)

Q ：晚上好， 巴夏。

B ：你好。

Q ：我的问题是关于我丈夫在积极参与的一个自发的社区。 B：好的。它是什么性质的？

Q：它好像是一个没有管理机构的社区。比如说，没有人能…那里没 有警察，如果你不交税，不会有荷枪的警察来强迫执行。基本上，完全没 有管理机构。

B ：好的。某种意义上，这正是我们文明的存在方式。

Q：你能为我大概介绍一下吗？

B：好的。我们社会并不存在一个执行管理的“政府”，而是有一个组 织体，但他们所做的就只是“确保信息流向需要它的地方”。他们就只是 做这些。这就是我们社会的组织体。它只是一个信息交换体。他们并不管 理或统治任何事务

这会奏效的原因是因为，我们对于“自治”的理解与人类完全不同。

让我们解释一下我们对于真正的“个体自治”的独特观点。可以吗？

Q ：是的。

B：谢谢。每一独立的个体，都像是一幅拼图中的一小块。当你有一 幅大的拼图，它是由一堆小的拼块组成的，是吧？

Q：是

B：每一块都有各自不同的形状，对吧？

Q：是

B：而且，每一块的形状恰好适合于一个特定的位置，对吧？当你把 所有的小块拼在一起时，无论它们的形状有多么的不同，当它们都拼在一 起时就形成一幅大的拼图。对吧？当每一个独立个体是它们真正的形状、 是它们真实的自己时，根据定义，它们就自动配合了其它同样也是它们的 真正形状的小块，这样就自动形成了一幅更大的图画，这幅图画也自动支 持着所有各个小块/个体。所以，不需要管理。

每一个独立个体的形状决定着需要成为的结构，并即刻的、自动的、 毫不费力的形成更大的图案，这个图案也就是所有个体形状存在的原因。 但是如果你努力成为你所不是的形状，你就不符合了，你也就不能配合其 它的小块，你也就不能形成那个支持着所有小块/个体的更大的图案。

地球上很多人相信，不能奉行个体自治，那样会出现无政府主义的混 乱。其实恰恰相反。当你们真正发出核心自我的振动，真正是你们被造之 时的形状时，你会自动符合你所属的位置，并自动支持着整体的存在。而 那个整体也就自动支持着你的存在。原理就是这样的。能说得通吗？

Q：能。那么他预想的这种无政府的社会形态，在将来有可能发生吗？ B ：是的，会发生的。

Q：那是未来几年后，还是未来几个世纪后？

B：说的是自现在开始到你们的 2050 年之间。

Q：好的

B：这种可能性会逐步增加，并在我们开头(巴夏 168) 描述的每一 个时间分界点以指数方式扩大。因为，记住：当人们以整合的方式联合起 来工作时，就需要更少的处于正面振动的人去超过那些分裂的、负面振动 的能量。
