# 巴夏 74 关于 2014 年的预告



翻译：觉醒者

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/k5xelku1-oQ.html)

在我们命名为“2014：再创的一年”的传述里，我们将会讨论分享一 些概念，来帮助你更轻松、更简单、更愉悦地，以你偏好的方式重新改造 自己、重新定义自己。去真正地将“你想成为的人”、“你想体验的生活” 的振频，结晶化出来。我们会将“再创”与“能量加速”的观念结合起来， 因为 2014 年的能量会在很多方面更加速，所以我们会与你分享，如何协 同、协调于这种能量，来使你能够在生活中利用它。

同时，也请密切地、更明确清晰地关注，不仅关注人生中那些代表着 你偏好的振频、观念、象征、概念，也要关注不代表你偏好的这一切。因 此，你就能更清晰地洞晓你的偏好与你不偏好事物之间的区别。

由于我们也会传述关于“冬至”的信息，所以我们会将上述观念结合 于 2012 年冬至的观念，这个能量现在发展到什么程度了， 以及它在继续 向什么方向发展。因此你可以以更贴切、更有实感的方式理解如何运用 2014 年的加速，并为你陈列出一种蓝本，一种模板来帮助你更清晰的决 定，你要如何走你的人生路途。那本就是你的路径，于即将来临的一年。 所以将会有更多的喜悦， 以及更轻松的创造于你们的实相中发生。

所以请参与进来，于此与我们分享的旅程上，当你跨过临界点而进入 新的一年，你们能开始得到更多的机会去更清晰、更有意识地以你偏好的 方式真正“再创”你自己。
