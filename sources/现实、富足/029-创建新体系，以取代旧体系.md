# 巴夏 125 创建新体系，以取代旧体系



翻译： 尚林

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/tssliuT8bRg.html)

Q ：我还有一个问题， 巴夏。

B ：好的。

Q ：太紧张了，我忘了要问什么了。

B ：好的。

Q ：抱歉。

B：这好玩吗？

Q ：不。我肯定你也觉得这不好玩。

B：我们觉得每一件事都很好玩，我们从不会觉得无趣，从不！我们 在任何时间都从不会做任何一件不好玩的事。你觉得这好玩吗？

Q ：是的。

B ：好的，谢谢！至少如果你要做坏事，就尽情的去做吧。 Q ：现在我要提问了。

B ：好的，谢谢。我们是想开个小玩笑，可能会把你带回那个振动， 让你想起你的问题。明白了吗？

Q ：对啊，谢谢！你谈到负面能量，而当我们寻找它出现的根源时， 都源自于恐惧。

B ：源自于恐惧，基于你们与源头分离的信念而产生的恐惧。

Q：是这样的。那么，我们说，现在世界上正在发生的事，我只是引 用我听来的说法，如果说，为了控制大众，是出于贪婪与权力欲，而将这 种信念输入人类意识—— 即人人都只顾自己，每个人都是我的敌人，如果 说一切都是被这些人控制的，而他们把这种意识输入人类意识...

B ：“这些人”是谁？

Q ：比如说，布什、布莱尔之类的。

B ：我懂你在说什么。我在努力使你从一个不同的角度来看待它。 Q ：好的。

B：是谁把那些人放到权力位置上去的？

Q ：我不知道。

B ：你当然知道。是你们所有的人。

Q ：是的，是我们。

B ：是的，你们。这就对了。“这些人”就是 (代表) 你们。你想要改 变吗？

Q：是的。我该怎么做？

B ：向世界传播这个观点：还有另一条路。只是去传播，不要期望别 人必须相信你。

去证明：还有另一条路。去实践：还有另一条路。示范给大家：还有 另一个世界，另一条路。事实上，并不是要去改变现有的体系，而是去创 建新的体系。当旧体系崩溃时，将有一个新体系来取代它。

Q：谢谢。那正好是我的下一个问题。那么说，我们并不是要如何“脱 离旧体系”或怎样在旧体系中找出路…

B ：是要创建一个新体系。

Q：恩，创建一个新体系。谢谢！

B：这样，当有人在寻求一个能代表他们理想世界的观点时，他们就 会找到像你一样的人共同创建了的新体系。当有足够数量的人们找到了新 体系，他们就会让旧体系走开；而那些想要抓住旧体系的人，将会跟着旧 体系一起走开。就是如此简单！

你们并不是要努力迫使任何事物发生改变，否则，你们所做的一切就 与你们现在抱怨的那些人一样，使用了同样的策略手段。所以，去做一个 与众不同的人，以不同的行为方式去创造不同的事物。这样，你就会为新 观念提供基础，人们会受到新观念吸引并能够继续发展它，某种意义上讲， 新观念的发展将最终取代旧体系。

但再次强调，要记住，真正发生的是：通过那样做，你在改变自己的 频率，转换自己，使自己穿梭于一系列平行实相之间，越来越接近于你偏 好的平行实相，直到某一天，你会发现你已身处那个实相中了。

你也可以跨越所有的中间步骤，但是，如果你的灵魂选择探索的主题 就是去创造这些转变的步骤，那么你就不会跨越它，你会经历这些步骤。 但不管怎样，你所做的仍然是平行实相间的转换，你并没有在改变已经存 在的实相，那个实相仍然在那里，那个实相“仍然”在那里。

比如说，我们知道，你们中的许多人越来越多地开始注意到环境的无 害化。你们在减少污染，你们在寻找替代能源，这很好。但是那个被严重 污染的世界依旧存在着，那个被污染的地球依旧存在，你并没有改变什么， 只是，你已经在你之内创造出一种新的振动，使你转换到一个与寻找无污 染的替代能源这个观点更加一致的新世界中，而那个世界早已存在了！

你只是改变了自己的振动，把自己带到那里，连同那些与你有类似观 念的朋友们一起，你们都同意转换到那个新实相，因为那是你们偏好的。 但那个旧地球仍然在那里，它一直都存在着，你朝向的那个新地球也存在 着。它们都同时存在着！是你在转换自己的频率，你在改变着自己。懂了 吗？谢谢

新 Q：我想接着前面的提问，如果可以的话。

B ：可以吗？我不知道。

Q ：如果你觉得可以的话。

B：可以吗？让我和我的伙伴们商量一下

Q：慢慢商量~

B ：噢，好的。令人惊讶的是，他们说可以。

Q：好极了！真是震惊，谢谢你。其实我刚才是想问你，我能否不出 声的向你提问。可以吗？

B ：不行。

Q：好吧，假如我们刚才讨论的真的发生了，某人改变振动向特定的 方向，比如说，战争。比如说，我们中有一个人，转换进入一个平行实相， 在那里没有战争那么，对于认识这个人的其他人，看起来发生了什么？

B：视情况而定。看上去可能有很多种情况。另一个实相中的人也许

看到你被杀了而你，以你的视角看到的就只是，也许由于某个无法解释的 原因每个人都突然停止了战争，你可以有任意种方式来感知到这种转换。 这取决于感知者需要看到什么，来使他们能够理解。

如果某人真的有可能发生特定类型的改变，他们可能会看到你只是消 失了。但他们也可能只是看到你被杀了，或者只是转身发现你不见了，却 不知道你去哪里了，还以为你随便走开了。其间的任何情况，都取决于感

知者需要看到什么。

明白了吗？
