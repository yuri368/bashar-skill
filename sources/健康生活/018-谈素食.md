# 巴夏 85 谈素食



翻译：柯维

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/A70A-elsQsw.html)

Q：只食用植物产品的素食者或者素食主义者，是不是就有更高的振 动频率？

B ：可以以那种方式起作用。但是，(素食者是否就有更高的振动) 取 决于个人。有许多人不是严格的素食主义者或者素食者，同样拥有很高的 振动。这仅仅是取决于你要探究什么，你怎么样探索，你怎么样与事物协 调。对你们星球上的许多人，它是可能的，甚至大致来说是真的，即清淡 饮食都会有益于更高频率的能量。

但是事情总有例外，所以要具体问题具体分析，明智地跟随你自己的 本能，你自己的身体意识，你的最高的兴奋喜悦，什么食物对你而言是自 然恰当的。

但是，再次的你记得吗，耶稣也是吃鱼的，对吗?

Q ：是的。

B ：所以啦~~所以真正的，你要明白的是你和食物之间是什么样的关 系。你感激动物们将自己作为礼物来支持你吗？对此你有什么样的理解？ 这取决于你与食物之间的关系。许多土著部落一直以来都和他们吃的那些 动物之间保持着很好的关系所以，他们吃动物肉并不会以任何形式降低他 们的振动。你明白吗?

Q ：是的。

B：所以，通常的理解就是，当你提升你的振动，可能你会感觉到更 少的需要或者更少的想要进食更致密的食物(肉)，但是只要让它自然而 然的发生就好。如果你感觉很想成为一个严格的素食主义者或素食者，那 么就去做吧，看看会发生什么。然而，如果在那个过程中你忽然感觉到有 必要摄取一些非素食的蛋白质类的食物，相信你的身体意识，它知道它需 要什么。你可能不需要很多，但是身体可能需要必须的最小的量 (非植物 蛋白) 来维持某种平衡，可能是你通过严格的素食无法获取的营养。

但是再次的，什么对你最适合、对你最有效，这取决于你个人的频率。 没有必要强迫你自己更加的灵性，那就矛盾了。(注：指强迫与灵性是矛 盾的。)

B：说的通吗?

Q ：没错。

B ：好的。
