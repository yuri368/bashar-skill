# 巴夏 56 身体疼痛与情绪压力的关系

Q ：你好， 巴夏。

B ：你也日安。

Q：你能告诉我我正在经历的膝盖和小腿肚后面的生理疼痛与情绪压 力之间的关系吗？

B：你不觉得你的描述已经给出答案了吗？

Q ：哈哈。我还是想要你的答案。

B：那个意义上的压力，怎么说呢，把你锁在了一个特定的位置，让 它不容易有弹性，你明白吗？

Q ：是的。

B：你不想去着手做的那个事是什么？

Q ：我困在了我正经历的家庭情感问题里。

B ：你困在了家庭情感问题里，这意味着你意识不到你内在的某些定 义和信念体系。因为所有情绪都来自于信念和定义，你不会对什么事物有 任何感触，除非你首先相信它是真的。所以，如果你想要解困，就应该去 发现是什么信念和定义在创立那种你正在体验的情绪。最主要、最直截了 当的方式是，每当你感觉到那种情绪的时候，首先拥有这种情绪。因为你 无法改变你不拥有的东西，然后，承认它是在给你一个信号，它在告诉你 你正在经历你们所谓的“负面情绪”，就只是因为你在用负面的信念体系 过滤着你的能量。因为，当你的能量流经特定的信念体系时，情绪就这样 产生了。所以，当你有某种情绪体验时，你唯一要做的就是问自己：我非 要把我与境遇的关系的哪一部分信以为真吗？

当你找到对于你所处的境遇来说什么才是真的时，如果你足够仔细地 聆听，你会发现你对你和境遇之间的关系有着怎样的信念。当你找出那个 定义、意识到那个定义时，如果那个定义与你的真实自我不协同一致，它 会突然显得不合逻辑并且讲不通，然后你就可以放掉它。因为任何与你的 真实自我不协同一致的事物都会显得不合逻辑和讲不通的。所以，你必须 把不合适的信念从无意识中带到显意识上来。因为一旦你认出了那个信 念，你就能放掉它。但如果你不把它提到显意识认知上来的话，则会一直 引起情绪反复发作。这样说清楚了嘛？

Q：是的。所以你基本上说的是……去感受我的感觉？

B：是的。找出是什么产生了这种感受，找出你非要去相信的是什么， 你非要去买的是什么信念和定义的帐来感觉到你正拥有的感触。因为如果 你没有一个定义的话，你也不会有任何感受。如果我对你说一个你没有定 义的词语，你不知道如何对之感触，不是吗

Q ：嗯。

B：这不就对了嘛。一旦你有了定义，你就开始不断地将之注入意义， 因为你给那个情况注入的定义结构。但一切境遇根本上是中性的，它们不

带天生实有的意义，它们毫无意义，人生从根本上讲是没有意义的。我这 么说不是消极的。意思是你被设计来给人生注入意义，你决定着事物的意 义。它们不会自动地意味着任何事。它们只是中性的，只是些小道具。

所以不管什么情况出现，无论表面上看起来如何，如果你开始给它， 授予它更多的积极意义。首先，允许它是中性的，退一步，冷静一下，然 后说：“等一下，我不需要做出反应，这是中性的”，然后无论什么原因授 予它一个积极的意义，那么你就只会从中得到积极的结果，无论那个情况 下别人可能对你有什么企图。你明白吗？

Q：这是个很美的答案！

B：哦，谢谢你！现在，你在实践你的喜悦与兴奋时是否也感到犹豫 踌躇？

Q ：不，完全没有。

B：你是说你没有犹豫，还是没有去实践？

Q ：没有实践。

B ：好吧。那么对于实践你的最高喜悦你在害怕什么？你相信如果你 那样做，会发生什么？ 因为你看，这是另外一种探索你的信念的方法。如 果你有恐惧，那么就探索它，扩大它，放大它，把它提到明处，然后说“好 吧，如果我真的这样做了，我害怕的最坏的情况是什么?然后放飞你的想 象，变得害怕，放大它以至于你能够找出那是什么信念，什么定义。

一旦你知道了那是什么，你会开始看出那不合适你、不属于你、讲不 通、不合逻辑，最重要的那不属于你。它也许来自父母，也许来自社会， 也许来自同伴，但你不是必须要买它的帐，因为你要体验到任何事的唯一 途径就是你自己同意体验它。

所以如果那个信念来自于别人，并不真的属于你，就丢掉它。因为如 果你一生都背着一个不属于你的东西，这叫做偷窃。你在偷窃别人的信念。

它们不属于你。所以丢弃它们，交还它们，“哦，这些不属于我， 回到信 念替换去，我想交还这些，它们不属于我，并且它们很沉重，我受够了， 我不想在我的人生里拖拽它们，而且它们让我关节疼。就没问题了。你跟 上了吗？

Q ：是的，非常感谢。

B：谢谢你！
