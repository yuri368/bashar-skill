# 巴夏 124 境遇是中性的，你赋予它意义



翻译： 尚林

视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/qAFEZDSS7lo.html

Q ：你好， 巴夏。

B ：你好。

Q ：我知道这个周末我选择了痛苦。

B：噢，好的。你为什么那样选择？

Q ：我遇到了信仰问题。这个周末我从绝望和愤怒转为希望，因为我 听了你的传讯，我差不多要找回信心了

B：你有超越信仰、抵达知晓 (knowing) 的状态了么？  (注：  《超 物理学》中有关于“知晓”的解释。)

Q ：没有。我在想你能不能再给我多讲一些，好帮助我恢复坚定的信 仰 …

B ：我不是试图把你带向坚定的信仰，我是试图带你超越信仰，抵达 知晓。你有没做过“我是” (IAM) 那个冥想练习？

Q ：我做过。

B：你能否理解，当你说“我是”的时候，你所宣布的就是一个绝对 的事实？

Q ：我理解。

B：那么说你懂了。就那么简单。当我们说“就那么简单”时，你不 相信我们吗？相信它有困难吗？

Q ：我的困难在于，当你说“境遇不重要”时，我很难接受。我想知 道，我如何才能相信它从而证明它。

B ：噢，谢谢。我们已经说过，——我们知道，这句话以你们的语言 咋听起来是什么感觉，但我们的本意它并不是负面的意思—— ，那即是： 我们被给予的最伟大的礼物就是“生命是无意义的”(life is meaningless)。

情况和境遇本身并没有意义，它们只是中性的道具。我来换一种说法 吧。你们在一定程度上已经意识到，我们之前说过的：任何境遇都能产生 甚至相反的结果，或相反的感受。是吧？

Q ：是的。

B：在任何情况下，你能够在完全相同的情况中看出积极的后果，也 能看出消极的后果。对吧？

Q ：是的。

B ：这表明，任何情况的意义都不是预设的，固有的，它的意义取决 于你如何看待它。所以，如果你决定某个情况会对你产生正面影响，它就 会对你产生正面影响；如果你决定它会对你有负面影响，那它就会对你有 负面影响。情况自身并不具有预设特征说它将对你有正面或负面影响，那 个决定权在你手中。所以说，任何事物本身并没有预设意义。这就是为什

么我们说“境遇不重要，重要的是存在状态”，因为是“存在状态”使你 决定了要为根本上是中性的境遇赋予怎样的意义。

Q ：但是，当某人故意施加伤害时，你又如何以正面的方式来看待它 呢？

B ：好的，谢谢。观察到某事是机制上的负面，或是机制上的正面， 这两种观察方式是有差异的。这个意义上：“负面”是指“分离的”；“正 面”是指“整合的” 。能理解吗？

Q ：不能哎。

B：你不理解啊。好吧，当我们谈到“正面的”与“负面的”时，我 们并不是在说主观上的“好”与“坏”，我们说的是能量的机制描述，这 个意义上：“负面的”指的是分离的，分裂的，孤立的，断开连接的，这 些形式的体验；“正面的”是指整合，联合，统一，结合，一体化形式的 体验。这个能理解吗？

Q ：能。

B：如果你有一个基于恐惧的定义系统，你将会体验到更多分离的情 绪以及更大的恐惧，这样你会看到，负面机制通过持续地在你的信念体系 内产生更多怀疑，更多分离，更多恐惧，更多与你核心真我的不一致，从 而产生另一个扩大版本的负面机制。恐惧本身，就是负面信念系统的表达。 明白了吗？

Q ：明白了。

B ：所以，当你看到某人正在做出负面行为，或者当你看到某人正遭 受伤害时，你能认出，那里可能有一个负面的信念机制，然而，你也可以 认出，那个人无须为他的负面行为申辩，他也可能会使别人从中学到一些 积极的东西，或者可能给别人带来正面的影响。

我给你们举个很简单的例子吧。我们理解，当某人辱骂他人时，那是 个负面事实，是由他的负面信念造成的，它是分离的，孤立的，分裂的， 隔离的。然而，如果你遇到这种情况，看到某人受到辱骂，你介入进来帮 助他，那么你就是在注入正能量。而且假如你会说：看到这种情况，我现 在受到强烈启发要做一些事，确保这类事不会在我们星球上的任何地方再 次发生。那么你就是在以一个负面的体验为起始，来创造出一个正面的效 果。

所以，关键在于你如何利用它。这就是为什么我们说“境遇不重要”。 并不是要忽略境遇，只是让你知道：你赋予境遇怎样的意义，决定了你会 从中获取哪种效果，并应用于你的现实。记住，每一个正在经验的人，在 根本上都是一个永恒的、无限的灵。最本质上， 每个人都是安好的 (Ultimately everyone is just fine) 。

我要用通俗的话来讲：每个人都会进入天堂，不管他们以前做过什么。 因为那是唯一存在的地方。要知道，你是被创造的无条件之爱，天堂是返 回无条件之爱的唯一的地方。

虽然，某些个体也许知道，他们不想选择某种特定方式的体验，因为 那已经为他们创造出一个更加负向的而不是更加正向的体验。而他们会从 自己选择的体验方式中学到某些课程。那由他们自己决定。

但关键在于，当我们说“境遇不重要”时，我们只是想让你们明白：

境遇从根本上是中性的，你可以决定它们对你的现实产生怎样的影响，你 将如何利用那个经验。

某个体验开始时是负面的，并不意味着你只能从中获得负面的体验。 你确实可以好好利用它学到课程，从那个负面体验中真正创造出一个非常 正面的现实。能理解吗？

Q ：是的。

B：而且，当我们说“境遇不重要，重要的只是你的存在状态”时， 我们是在玩“matter ”的文字游戏。  (注：matter 既有“物质”也有“重 要”的意思) 使你们的实相物质化的，并不是境遇，而是你的存在状态， 存在状态物质化了你的实相和体验。境遇只是中性道具，它容许你决定， 通过境遇反映出你是否与真我谐调一致。

有帮助吗？

Q：很有帮助，谢谢！

B ：非常感谢！
