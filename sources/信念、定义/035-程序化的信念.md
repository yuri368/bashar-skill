B：关于那些信念的一些东西，你有其他的信念说：“你必须保持相信 那些东西。”但是如果你找出这些信念是什么，找出这些说你必须一直相 信那些引起战争的信念，并改变那些基本信念，然后，你会改变次生信念， 这样，就不会有战争了。

所以，任何时候，如果你发现有一个结果指向一个你没有在改变的信

念，那就说明，有另一个信念说，那个信念不应该改变。你必须找出那个 信念是什么，并改变它。而那个时候，如果又有一个信念说，你不应该改 变，你就必须再次找出那个信念是什么，并改变它。

一直往上走，进入你的真实核心，并找出真正的“第一核心信念”(first core belief) 是什么，它衍生出所有其它信念，而这些信念创造了你不想 要的现实。这么说是不是更有道理？

Q ：是的。

B ：谢谢。

Q ：谢谢。

B ：你只需要真正地探究这些信念到底是什么。因为你已经创造你自 己成为众多层面的，你令那些信念隐藏起来，所以除非你意识到那些核心 信念是什么，你不会知道该怎么放手其他信念。也许正是那些信念带来了 你不想要的事物。但是，这些你不要的事物总是来自于你的信念，总是这 样。使事物显现的、首要的是你的信念。

如果你没有事先相信一些什么东西是真的，对那东西有一些信念，你 就绝对绝对绝对不会对任何东西有一个感觉，或一个情绪，或一个想法， 或一个行为。如果你对一个东西没有定义，你绝对不会对它有感觉或想法。 你懂我意思吗？

Q ：是的。

B：如果我说“con do lock ta su,bo ron ta zei”，你对这句话有什么感觉 吗？

Q ：没感觉。

B ：因为你对它没有定义，是吧。

Q ：对啊。

B ：好。那么，一旦对某事物有了定义，你就会开始产生感觉。如果 我说，刚才那句话翻译成你们的语言意思是“我们每一天都无条件地爱着 你”，那么你就开始对它有了感觉了，因为你现在对它有了定义，明白吗？

Q ：是的。

B ：就是这么简单。所以，任何你有感觉的东西都是源于信念，在信 念中，你与那个东西有一种关系。因为，任何感觉、任何想法、任何行为 都来自你怎么去定义它，你怎么去相信它的真相。这一点对你有帮助吗？

Q ：是的，谢谢。

B ：谢谢。

Q ：巴夏。

B ：是。

Q ：我想要继续谈谈这个话题。以便确定我自己的理解

B ：哦，好的，当然可以。

Q ：所以，我们就来说说“战争”这个概念吧。

B ：是的。

Q ：我认为我们都相信：战争是负面的、具有毁灭性的。我们都不想 在自己的生命中去体验战争的伤痛，至少这是我们对战争的感觉，但是， 如果我们追溯“战争”形成的信念并改变我们之内的那个信念。那么，寻 求终止外界的战争，就是不必要的。但是它只要…

B ：哦，是的是的是的是的是的。改变信念，最终你会发现外界也改 变了。再一次，请记住：事实上，它并不是关于改变外在的事物，它是关 于改变你自己的。当你充分地改变了你自己的时候，那时你会发现你已经 转变你自己进入一个平行现实。那个平行现实是和你的新信念一致的，在 那个平行现实里，只会有跟你信念一样的人存在；在那个平行现实里，没 有战争。

也许从一个物质的观点来看的话，不会有战争的原因是因为：“也许  一些人相继死去，再也没有这些人来制造战争了；或者也许他们只是不知  怎么的消失了，你不知道他们发生了什么事，但是他们再也没有出现了；  或者也许发生了一个自然灾害，他们都被灭了，所以他们再也不在了；或  者也许他们只是有一天决定说，他们厌倦了战争，他们再也不想打仗了。”

许许多多不同的方式可以被创造来产生一个情况好像他们已经改变 了。但是，事实上发生的是：你已经转变你自己进入了一个平行现实。在

这个平行现实里，战争跟你是谁不再是一致的。这样说有道理吗？

Q ：是的。是不是有一个门槛什么的。需要有足够的人按那种方式感 觉并改变那些信念？

B ：是的。而那就是 2012 年的意义，2012 年代表了一个“门槛”，当 你跨过了那条线，你们地球上的积极能量终于真正地比消极能量多了一点 点。此后，它会开始滚雪球。从 2012 年起，正能量开始急速增加，你们 终于让能量的天平足够倾斜，以至于可以保证从那时起，我不是说——它 会是第二天——但是从 2012 年起，相对迅速地，一旦在这个星球上的主 体能量天平从消极能量转向了积极能量，那么地球转变就会真正加速。

因为，请记住：要让积极能量超过消极能量，并不需要积极能量导向 的人跟消极能量导向的人数一样多，因为积极导向的人是融合一体的，而 消极导向的人是分裂的。你懂我意思吗？当地球的能量天平最终向积极能 量一边倾斜时，这种变化将以指数级扩张，而 2012 年这个时间点就代表 了这个能量转变的“门槛”。从那时起，能量会更积极一点，这会加速你 们的能量，直至 2033 年到 2050 年之间的某个时间点上，你会发现战争会 永远地消失了。
