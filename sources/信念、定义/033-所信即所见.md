# 巴夏 31 所信即所见



(Believing is Seeing) ——信念的力量

翻译：happytrails        校译： 尚林    整理：风

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/8j0ZhSFwrXA.html)

B ：只要你做出选择，你就会逐步接近那个目标；只要做出选择并行 动，你就会趋向目标。

Q ：我想可能是在你接热线的时候……

B ：我？

Q ：是的。

B ：你也有一条热线，你知道吗？

Q ：我知道。但是很明显在我脑海里出现了一些干扰。

B ：很明显？对我来说一点也不明显。

Q ：我想，我没有清楚地获得相关讯息来帮助我走出困惑，所以我现 在常常对生活中的很多决择和情况感到困惑，我似乎没有方向感。

B ：你是否在每一个时刻都做着最令你兴奋的事——如果当时你有能 力做到？或许，你没有行动、而是在等待一些更好的情况到来？

Q ：我……

B ：你是否自行否定了那些令你兴奋的事，只因它们看起来很琐碎、 表面上看上去它们与你真正想做的事无关？

Q ：嗯，有时候我想我作为一个“卫生官员”已经做得太久了，所以 我打算退出并尝试着去让其它新的机会进入……

B ：你想做什么？什么事情是最令你兴奋的？你是不是一直在做其它 事情的，因为你不相信你能做那件最令你兴奋的事？你感觉你不得不忙碌 于工作，为了使你达到一个能随心所欲的做令你兴奋的事情的那个点，对 吗？

Q ：恩……

B ：有没有令你兴奋的事情——是什么？

Q ：有的，我想搬到小镇的西边去。然而似乎很多事情把我带到了与 搬迁无关的事情上。

B ：你为什么想要搬迁？

Q：因为我不喜欢我现在住的地方，我对现在呆的地方并不真正喜欢。

B ：你真正想在生活中做的是什么？除了搬迁这个想法外，什么是令 你兴奋的。

Q ：噢，我的事业

B ：谢谢，哪个更令你兴奋，事业还是搬迁？

Q ：事业。

B ：好，那么为什么你要专注于搬迁这么一个细节呢？这只是当你在 朝向最高喜悦行动时，就会自动就位的其中一项。

B ：嗯，如你所视，我没有足够的信任。

Q ：因为我看不到，对事业的追求如何能将搬迁这件事带入现实…… B ：原来如此！信任！为什么不呢？为什么不？

Q ：我只是看不到它如何可以 ……

B ：为什么它不能？我可以问你一个问题吗？

Q ：当然。

B ：你希望追求事业会带来搬迁吗？

Q ：当然。

B ：那么就那样去看它待。

Q ：好的。

B：“所信即所见。你相信的什么，就会看到什么。”(believing is seeing) 而不是“先要看到，才去相信”。在你看到它实现之前你必须先相信它。 只要你相信，你就会看见，我保证！

Q ：相信即显化的力量？那么，是不是任何我们相信的事，它都会给 出一种信心使它发生？

B ：有，在某种意义上有。但是“相信，就会看见”的意思是：在看 到改变的景象发生之前，你必须先迈出第一步。否则，如果你不去行动， 很明显什么改变都不会发生，你将会停留在“你以前一直呆在的那个地 方”，直到你迈出第一步为止。

Q ：但是我有在改变我的信念系统啊~

B：这样啊~但你刚才表达出你不愿意相信：你能快速改变实相、想多 快就能多快。你不相信，或者说你不愿意相信：“如果你只是按照你的最 高喜悦兴奋去行动，你所需的所有要件都会自动到来、服务于此，并允许 你继续去做下一个最令你兴奋的事。”而如果做你最兴奋之事需要你处在 一个新的、更愉快的环境，那么，这个环境会被自动吸引到你的生活中来， 否则你没法去实践你的最高喜悦，而那种事是不会发生的。

在任何你力所能及的范围，按照你的最高喜悦去行动，所有应该出现 的 (以使你跟随最高喜悦) 的情形、环境、人际关系中的构件都会被吸引 过来。那时你所要做的就是：当它们到来时，充分应用它们。因为当它们 到来时你会认出它们。这不会是一个困难的决定。明白吗？

Q ：明白，我想我现在遇到阻碍，我想你也许能帮助我……

B ：“阻碍”只不过是你不情愿移动到那个对你来说是显而易见的方 向。那就是阻碍。它只是缺乏信任。仅此而已。你们从来没有人真正受到

过阻碍。它仅仅是不愿去相信——你真的知道你需要知道的一切。一切都 简单明了，但你们却更愿意使它复杂化，你们想：我肯定遗漏掉些什么， 它不可能那么容易，它不可能那么简单，它不可能会起作用，我不能盲目 听信，事情看起来不一致，看起来彼此没有关联性，我不可能做着这件事， 另一个把我希望的事就会出现……

为什么不？为什么不？为什么不？你们所说的这些都只是一些假设。

它们仅仅是你们所受教育让你们形成的信念，除此之外没有更多支持其成 立的基本事实或牢固根基。你可以决定：你愿意去相信哪种实相创造体系。 你所相信的，它就会对你起作用。

所有的信念，所有的信念都自发地对其系统产生不间断的支持。因此， 我们说：你相信的任何事，都是真的、都会起作用。很简单。

过去，你们星球上的人们找到了一个服务于他们的系统后，他们设立 了一个假设：它会是地球上唯一可行的系统。然后他们就完全忘掉了在这 之前曾有另外一个系统同样很好地服务于他们。要意识到：所有的系统都 有效——只要你相信它。

你可以从中领会到这样一个事实，不同的系统只是同一个“一切所是” 的不同表达，以祂所能的一切方式进行自我显化。所以，当你不断地下定  义、来定义你所愿的系统，并相信它将和其它你所创造的系统一样有效， 并以这种态度去行事时，它就会像其它任何系统一样有效地服务于你。你  没有必要问：“其它系统会不会对我有效？ ”当然，它们都有效(只要你  相信它)。

因为，你由负面信念所创造的是一个消极运作的系统。所以当你说“好 吧，我不相信我能做到这”或者“我相信这不会发生”，你得到的就是“不 能”和“不发生”。不能以相应的方式运作的事物就不会发生，它的运作 一开始就完全百分百地反映着你最强烈相信的事情。

所以，当你改变信念，你就改变了事物的运作机制——你借以创造了

自己的实相；你将获得相应的结果。我保证。这就是一个信不信任的问题， 但是如果你知道它就是一个信任的问题，却只在口头上相信，行动上去并 不依照它，那么它就只是一种借口。因为如果你知道你是出于习惯，它就 不再是一个习惯使然(不再是一个无意识行为)。它只是一个借口。明白 吗？

Q ：我是在改变我的信念系统，但我仍不见其显化，怎么办？

B ：不要去期待事情以你觉得它应该如何发生的方式发生，让事情通 过阻力最少的途径到来。因为你不具有能力来分析和理解所有可能发生的 方式。当你专注于你认为它应该到来的方式时，你已经关闭了其它所有可 能使它更快到来的机会之门。明白吗？

向一切可能性敞开——这就是信任的全部内容。对一切事都说：好的， 好的。我认为我需要的是这个，不过，另一个是真实令我兴奋的，如果我 以自己所能的任何方法或形式，真正按照我的最高喜悦去行动，我将信任： 我真正所需的一切都能在我继续跟随最高喜悦的过程中自动到来并彰显 它们自己。当它们出现时，我会毫不犹豫地照此行动，即使它们不是我原 本期待的。难到你不想要生活中出现惊奇吗？

Q ：当然，我每天都有令我惊奇的事情。

B ：那么，就认出它们，让它们成为正面的惊喜。你只要始终跟随自 己最高的喜悦和兴奋，所有的要素将会自行就位，以允许你继续朝这个方 向前进。这是一个简单的事物运行机制。但是你要在看到它实现之前完全 的信任它、并照此行动，它会真的发生作用，我保证！不会有意外情况， 包括你在内。

Q ：好的，谢谢。

B ：谢谢。不过还有一件事，记住，对你们很多人来说，探究你们自 己的信念是极其重要的。通过你们所创造的现实境遇，来探触到 (创造了 这个境遇的) 自己的信念。允许自己明白：无论你是否相信发生在你身上

的事是恰当的，事情都会改变，因为很多东西都处于你自我的无意识和潜 意识中。你在自我的无意识和潜意识中创造了这些东西。

所以，无论你现在经历着什么，它都是在给你时机去发掘你内在的一

切，从而，你能够充分定义你所做的事情而不受其他任何束缚。这样，当 你不喜欢它时，你将具有充分的能力重新定义它并做出改变，选择你真正 更喜欢的现实体验。
