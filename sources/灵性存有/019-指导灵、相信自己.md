Q ：你好， 巴夏。

B ：祝你今天好心情。

Q ：谢谢，也祝你有愉快的一天。

B ：请快点进入正题。

Q ：好的，我有一个简短的问题：我与昴宿星 (pleiadan) 文明之间有 关系吗？

B ：你是指昴宿星团吗？

Q：是的，谢谢你纠正我的发音。(注：视频中没有巴夏声音上的回答， 但观众都笑了，应该是做了手势或者其他肢体动作。在后面的对话中巴夏 也提到提问者和昴宿星文明有关系。接下来提问者说：yes。) 嗯。

B ：下一个问题呢？

Q ：喔，好的。我想问是否有任何信息从我的指导灵 (spirit guides) 那里传来？

B ：一直都有啊，难道你听不到吗？你感受不到吗？

Q ：是，我感受得到

B ：那么你为什么还来问我？

Q ：因为你总是对的

B ：恩，这是一个很好的问题——你为什么问我？

Q ：我只是在问你是否——

B ：你为什么问我？

Q ：我也不知道。

B ：你知道的。

Q ：好吧，我知道。

B ：你在怀疑你自己，是吗？

Q ：是的。

B ：谢谢你，谢谢你的诚实。你为什么怀疑你自己？为什么你怀疑你 所感受到的事物？

Q ：我只是怀疑我自己。我不知道。我总是时而相信时而怀疑，左右

摇摆，我不确定。

B ：左右摇摆？哪个是左，哪个是右？？你愿意活在当下吗 Q ：是。

B ：那好。活在当下会更开心吗？

Q ：当然。

B ：好的。灵感从哪里来真的重要吗？是的，你们所有人都和自己的 指导灵有各种不同形式的连接。你们所有人都有指导灵，他们在不断地与 你们交流。而你是否能接收到，取决于你接收和甄选的能力。

是的，你们中的很多人都与外星文明有联系，你也确实像很多其他人 一样与昴宿星和天狼星人有联系。但是，主要问题是它如何应用和帮助到 你的实际生活。如果你能依循灵感做你真正喜欢的事情，那么你接收到的 所有信息将会让你更加有能力在物质实相中做真正的自己。所以，就该好 好注意你的灵感和你的想象创造，并且信任它们。不是吗？

Q ：是的。

B ：你愿意那样做吗？

Q ：当然。

B ：为什么？

Q ：因为那是我的最高兴奋所在。

B ：因为那些就是“你是谁”啊！

Q ：它是“我是谁”。

B ：这回答了你的问题了吗？

Q ：我想回答得非常清楚。

B ：那你回答了我的问题吗？

Q ：没有回答你的问题吗？

B ：没有。为什么你要怀疑你自己呢？

Q ：我再也不会了(I don't any more)。

B ：谢谢，非常好！

Q ：我真的不会再怀疑自己了。

B ：要知道，这与我们之前说的“从一个平行现实转换到另一个平行 现实”有关系。再一次我们提醒你们所有人，请铭记：你们所谓的物理人 格只是一种人为构思的结果，它借由信念、情感、思维模式和行为来定义。

当你说“我再也不会了”你就转变成一个新的自己，确确实实是一个全新 的自己。(关联信息： 巴夏 21 和巴夏 022  (不是 22) 等等)

因此当你真正意识到：在你发生转变的那一刻，你确确实实 (而不是 比喻) 转换到一个新实相中成为一个新生的人。那句话就不会是“我再也 不会了”，而是“我从没有怀疑过自己 (I neverdid)”。因为过去不属于这 个新生者，他有一个崭新的历史。

因为你经由当下创造了你的过去。因此如果你确实转换成了一个新生 的人，那个新生的人就没有在转换的那一刻之前的那个人的历史。当你确 实转换成一个全新的人，你就已经为自己创造了这条时间线上的所有一 切。所以，不是“我过去没有做过 (I never did)”，而是“我从不曾有过 (I neverhad)”。现在的这个我，从来没有怀疑过自己。

Q ：哦，是的是的。

B ：这样能理解吗？

Q ：完全明白。

B ：你以这种方式来锚定，使它不再改变。

Q ：谢谢你，当然是的。

B ：谢谢你。

Q ：谢谢你。

B ：谢谢你，谢谢你，也谢谢我自己。(笑~ )
