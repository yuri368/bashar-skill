# 巴夏 163 同性恋



翻译：背背山

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/O9r4_HGHl7w.html)

Q：我是个所谓的基佬，同性恋人士，在这个世界上。我在 20 岁的时 候清楚的意识到了那个事实。那对我来说真是一种复杂的经历。我想那时 候我真是转换到了一个非常不同的现实当中。

B：当然。每次改变都是转换到一个新的现实当中，尤其是那些对于 你来说深刻的、与转换之前的现实相比非常不同的现实。说的通吗？

Q ：是，说的通。

B：好，然后呢？

Q：然后，我想知道我为什么要选择在这个现实中出生以后成为同性 恋呢？

B：哦，其中一个原因是为了给社会一个机会去理解，如何深刻的看 待他们的灵魂、他们的心灵，那既包括了男性能量，又包括了女性能量。 此刻在你们的星球社会上有许多焦点专注在了同性恋能量上，因为对于人 们来说，平衡他们内在的男性和女性能量是十分重要的。

因此，将更多的注意集中在了那种特殊的状态上，就给了每个人更多 的机会，更加意识到那个事实：你的灵魂或者精神既可以由男性，也可以 由女性来表达自己。实际上是其他几件事情。所以这就给予了人们一个机 会去平衡他们内在的能量，通过看到这样一个例子，就像你自己这样，愿 意表达出与他们已经选择的身体形式相反的能量来。说的通吗？

Q：是，说的通。我们既可以作为男性体验我们自己，也可以作为女 性体验我们自己。

B：是的。还有在物理形式上的变性人，双性人，无性人，等等，等 等。当然在其他社会里，灵魂有着许多种其他的表达，甚至和在你们星球 上的性别表达完全不相似。因此灵魂可以通过许多种的方式来表达它自 己，因为那是以那种方式的一切事物。

Q ：没错，我们人类文明是否有可能迈向那个方向呢？我的意思是， 我们的灵魂可以既表现出男性，又可以表现出女性？

B：是的。有的文明甚至根本不像你们这样的方式表现出性别的不同， 有的文明可以通过无性生殖来进行复制。

Q：那是什么？

B：无性生殖，意思是你可以简单地从你自己的身体上分裂出一块孢 芽或种子，然后长成另一个完整的人，其中没有任何的性互动。你们星球

上的一些动物和植物就是通过那种方法来复制的。

Q：现在我想问的问题是，我想说的另一件事是，我想当我意识到我 是个一个同性恋的时候，我从那个体验中所学习到的功课是，我开始更加 的意识到“什么才是爱”、“我们是如何体验爱的”。那就是我从我的体验 中学习到的。

B ：好的，非常好。

Q ：那就是我要说。

B：是的，谢谢。我理解，那就是为什么我对此没有什么可说的。因 为那是一个声明。再次的，那也是给你们的社会一个机会，将爱可以从许 多不同的形式，不同的角度来表达增添了更多的信息。以便你给予你自己 一个机会让更多的人，看到所有其他的不同的方式，让他们理解爱是可以 有许多种方式来表达的。

Q ：是的，我想爱就是一切，宇宙就是爱。

B ：是的，存在，存在的振动就是你们所说的无条件的爱。它就是那 样转化你的现实的。虽然无条件的爱可以通过其他的方式和其他的现实被 体验到，但是，它转换你的现实的方式就是通过体验、感觉到无条件的爱， 那就是存在自身的振动的重要意义所在。

Q：是的，同时也就是在那个时候，我开始更加的意识到了痛苦是什

么，如果你在这个现实中使用那个词的话。所以那时候我就下定决心，把 我整个生命都献身于帮助其他的同性恋人士当中。

B ：如果那让你感到兴奋，那就尽全力去做吧。

Q ：是的，那就是我一直以来所做的事情。

B ：谢谢，谢谢你跟随你的喜悦，谢谢你提供的帮助。

Q ：是的，那是我的欢乐所在。

B ：那也是我们的欢乐，就是我为什么要做这些传讯的原因。

Q ：真的很有意义。

B ：是的，谢谢，那就是我为什么要这么说。

Q ：好的。
