# 巴夏 117 关于堕胎，连续的痛苦经历



翻译： 尚林

(视频：http://www.tudou.com/listplay/P3sS3tkFQ3A/1a7R--Kp8Ho.html)

Q：你好， 巴夏！

B：你好！

Q ：谢谢，我爱你。

B：我也将无条件的爱送给你

Q：谢谢。我有一个问题，一个压在心头的问题。最近我怀孕了，面 临一个困难的抉择。

B：哦，困难在什么地方？

Q ：是去堕胎，还是要把孩子留下来直到出生。

B：那么你的决定是什么？

Q ：我刚刚决定了堕胎。

B：嗯，然后呢？

Q：我感觉快要疯掉了，因为这个决定反复困扰着我，我有宗教信仰 背景

B：哪种宗教？

Q：基督教。我和很多人交流了这件事，他们给了我很多相互矛盾的 信息，让我感觉快要疯了。

B：你现在感觉如何？

Q ：现在感觉很好，但我仍然有些迷惑。

B：迷惑什么？你真正想要问的是什么？

Q：我想知道，在堕胎时，胎儿身上发生了什么？

B：首先要知道，在受孕 49 天内，灵魂尚无法真正完全连接到那个身 体。这正是松果体 (pineal gland) 形成的时期。一旦松果体形成，意识的 表达就能够进入身体了。懂了吗？然而，要知道，你的孩子所代表的那个 灵、那个存有，他已经知道你会做出怎样的决定。他们还没有真正进入到 物质世界呢。明白吗？

没有什么事是偶然发生的。一切都是协同运作的。那个灵仍然存在， 仍然在你身边，仍然爱着你，仍然是完整的。你要知道，他的确想要经历 一次完整的物质生命；要知道，他或许只是想给你这次机会，来让你经历 这个过程。这种意义上，他选择以这种方式来帮助你，让你在这次测试中 体验你正在体验到的一切。

所有的灵，所有的存有，都是永恒的，不可毁灭的。你明白了吗？ Q ：明白了。

B ：物质实相只是一个暂时的构造，那个存有是完整无缺的。能跟得 上吗？

Q ：是的，谢谢你。

B：这对你有帮助吗？

Q：是的。我还有一个问题。自儿时起，我就在一直经历着接连不断 的伤害，一个接一个，一个接一个的伤害，就好像当我刚刚从一个伤害中

恢复过来，就开始进入另一个痛苦的经历中。所以我想知道如何结束这种 痛苦体验。

B：是的。那是因为你的信念系统全部都是关于“自我打击”的，就 如同你在这个堕胎问题上体验到的一样：罪疚感，罪疚感，罪疚感，一次 接一次，一次接一次的痛打自己、惩罚自己，惩罚自己，不停的战斗，不 停的战斗，我不值得拥有、我总是出错，我总是出错，我总是陷在深深的 痛苦中，我不配得，我不值得拥有……明白了吗？

Q ：听起来有些熟悉呢。

B：是的，我认为也是。我赦免你。但是，别人是否原谅你，这并不 重要。你需要原谅你自己。

Q：能够原谅自己的最好方式是什么呢？因为，我觉得我无法接近它， 或者说，那正是我一直努力想要的。

B：是什么在阻止你？

Q：我不知道！我以为我原谅自己了，但接下来的经历向我证明，我 并没有真正原谅自己。

B ：可能你有一个信念，使你无法真正原谅自己。

Q ：好的。

B：你怎么认识这个问题？

Q：可能吧，我怎么能- ……

B：让我来用另一种方式说明吧，假如你确实原谅了自己，你害怕会 发生什么？这可能是个最能启发你的问题。

Q：哦……

B：你能回答吗？你害怕什么，你恐惧会发生什么？---假如你真的释

放过去、原谅了你自己。

Q ：我不知道。

B ：你当然知道。

Q：我害怕什么？

B：对，你害怕什么？需要我提示一下吗？

Q：是的

B ：你确定吗？或者你愿意先谈谈吗，我不想打断你的思考过程。

Q ：好像是我无法足够接近去看清楚，我内心深埋的恐惧下面到底是 什么 …

B ：那并不是真正的问题所在。那是另一回事。

Q ：帮帮我吧。

B：噢，好吧，既然你这么温柔地请求。答案在这里。你准备好了吗？ Q ：是的。

B：你认为你是谁？亲爱的完美女士。你获得启示了吗

Q ：是的。

B：你比其他任何人都要好很多。你不应该对这些事感到难过，你不 应该对这些事感到愧疚。你认为你是谁？

你恐惧与你所爱的人疏远。你害怕突显自己 (standout)， 明白吗？ Q ：是的，你说的对。

B：你害怕人们说你很自我，说你比他们强，说你比他们更神圣。明 白了吗？

Q ：是的。

B：那好。你认为你能丢弃这些观念吗？

Q ：我能。

B：好的。要知道，你值得拥有幸福，你真的值得。因为假如你不值 得，你就不会存在。我向你保证。能跟得上吗？

Q：是的。谢谢你!

B：对你有帮助吗？

Q ：有帮助。

B ：好的。送给你无条件的爱。

Q ：谢谢你， 巴夏。

B：噢，你们星球上这些挑战啊！难怪我们来到这里后，我们如此震 惊。
